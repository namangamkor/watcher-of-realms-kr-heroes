워위키 v2.14.15 — 공개 후기 기준 영웅 목록 정렬 (누적 패치)

적용: ZIP을 풀어 기존 GitHub 저장소의 같은 경로에 파일을 덮어쓴 뒤 커밋하세요.
_worker.js, app.js, index.html, sw.js, hero-activity.css, collection-guide.css,
gear-detail-readable.css, newbie/index.html을 모두 포함합니다.
_worker.js는 반드시 저장소 루트에 반영해야 합니다. 새 CSS도 함께 업로드하세요.
기존 heroes.json 및 이미지 등 다른 파일은 유지하세요. DB 변경/마이그레이션은 없습니다.
Cloudflare 자동 배포 성공 후 페이지를 새로고침해 확인하세요.

동작:
- 승인되어 공개된 후기의 published_at 기준으로 해당 영웅이 앞으로 이동합니다.
- 모든 영웅의 공개 후기를 집계하므로 최근 소식 3건 제한의 영향을 받지 않습니다.
- 동일 날짜/시각은 기존 지정 순서로 정렬합니다. 활동 없는 영웅도 기존 순서를 유지합니다.
- 카드에 가장 최근 공개 후기의 한국시간 날짜를 '새 후기 · 월.일'로 표시합니다.
- 미승인/숨김/삭제 후기는 제외합니다. 좋아요/신고는 정렬에 영향을 주지 않습니다.
- 숨김/삭제 후 다음 페이지 로딩 시 남은 공개 후기 기준으로 다시 계산됩니다.
- 공개 취소 후 재공개해도 최초 published_at을 유지하는 기존 운영 규칙을 따릅니다.
- 필터와 검색에도 같은 정렬 기준을 적용합니다.
- 목록 로딩 후 API 결과를 반영합니다. API 장애나 JS 미사용 시 기존 지정 순서를 사용합니다.
- 실제 영웅 정보 수정일/수집가치/출시 순서는 덮어쓰지 않습니다.
- 향후 개별 정보 수정은 Worker의 WW_HERO_INFO_UPDATES에 heroId: Unix초를 기록하면
  해당 시각과 후기 공개 시각 중 최신 값으로 정렬하고 '정보 업데이트'를 표시합니다.
  과거 최근 소식(전체 장비 등)은 기존 지정 순서를 존중하기 위해 소식 표시만 유지합니다.

v2.14.12 영웅 순서와 뉴비 영상 버튼, v2.14.13 평점 안내,
v2.14.14 뉴비 영상 썸네일이 모두 포함되어 있습니다.
운영 배포는 이 파일 제공 단계에서 수행하지 않았습니다.
