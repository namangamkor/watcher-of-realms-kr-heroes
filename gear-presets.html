장비 프리셋 공유 코드 적용 방법

각 버전 상세페이지에서 공유 코드를 복사하세요. END V1.1은 46개 규칙의 공유 코드와 통합 입력표를 제공합니다.

  1. 위에서 내 단계에 맞는 설정 페이지를 열고 수집 기준과 주의사항을 확인합니다.
  2. 가져오기 전에 게임에서 사용 중인 기존 프리셋을 공유 코드로 보관합니다.
  3. 선택한 설정 페이지의 공유 코드를 복사합니다.
  4. 게임 내 추천 설정 → 프리셋 정리 → 프리셋 가져오기에서 코드를 입력합니다.

가져오면 현재 프리셋이 완전히 덮어써지며 되돌릴 수 없습니다. 기존 설정을 먼저 보관한 뒤 적용하세요.

장비 프리셋 자주 묻는 질문

성장용과 END 중 어떤 설정을 써야 하나요?

장비를 채우고 던전 단계를 올리는 중이라면 성장용을, 오래 쓸 최종 장비만 엄격하게 모으려면 END를 선택하세요. END가 모든 성장 단계에 맞는 상위 호환 설정은 아닙니다.

END 설정을 적용했는데 추천 장비가 거의 안 나와요.

END는 최종 장비를 압축해서 수집하도록 기준을 높인 설정입니다. 나만겜의 장비 던전 3-24 직접 테스트에서는 첫 100판 0개, 다음 100판 2개로 총 200판에서 추천 장비 2개를 얻었습니다. 이 기록은 해당 실험 결과이며 일반적인 획득 확률을 뜻하지 않습니다.

게임에서 추천된 장비면 END 조건도 충족하나요?

고대 신화·이화 신화·전용 장비는 이 규칙과 관계없이 게임에서 추천됩니다. 게임 자체 추천 표시와 END 프리셋 조건 충족은 구분해서 확인해야 합니다.

공유 코드는 어디에서 확인하나요?

성장용 V4.0 또는 END V1.0 상세페이지에서 확인하세요. 코드는 해당 페이지에서 관리하며, 적용 전 기존 프리셋을 보관하세요. END V1.1에서도 46개 규칙의 공유 코드와 통합 입력표를 확인할 수 있습니다.

각 페이지에서 수집 기준, 설정 이유와 공유 코드를 확인할 수 있습니다. END V1.1은 46개 통합 입력표도 제공합니다.
