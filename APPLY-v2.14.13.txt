나만겜 위키 v2.14.13 — 수집가치 범례 안내

v2.14.12의 뉴비 영상·영웅 정렬을 포함한 누적 패치입니다.
기존 v2.14.11 장비 제목·여백 수정도 유지합니다.

적용 방법
압축을 풀고 아래 7개 파일을 GitHub 저장소 최상위에 폴더 구조 그대로 덮어쓴 뒤 커밋하세요.

newbie/index.html은 newbie 폴더 안에 올립니다. 루트 index.html과 혼동하지 마세요.
ZIP 파일 자체를 올리는 방식이 아닙니다. 기존 저장소 파일을 삭제할 필요도 없습니다.
Cloudflare Pages의 기존 자동배포를 그대로 사용하며 설정·DB 변경은 없습니다.

이번 변경
- 유저 사용 후기 제목 바로 아래에 나만겜 수집가치 안내를 펼쳐서 표시합니다.
- 사용자가 확정한 1~5점 문구를 그대로 사용합니다.
- 해당 영웅의 점수에만 금색 배경·테두리와 현재 영웅 표시를 적용합니다.
- 범례 아래에 콘텐츠·각성 단계를 함께 남겨 달라는 재검토 안내를 표시합니다.
- 상단 수집가치의 물음표 안내를 평가 기준 보기 링크로 교체합니다.
- 링크 클릭 시 후기 위 범례로 이동합니다. JS 없이도 작동합니다.
- 모바일에서는 각 등급의 별과 설명이 위아래로 배치됩니다. 고정·따라다니는 UI는 없습니다.
- 댓글 기능이 꺼져 있을 때도 범례는 표시해 링크가 끊기지 않도록 했습니다.
- 기존 영웅 점수, 후기 작성·승인·신고 기능은 변경하지 않았습니다.

검증
Worker 구문 검사 및 256개 영웅 상세 응답 검사를 통과했습니다.
DOM 검사에서 5개 등급 문구·현재 등급 표시·링크 대상·후기 작성란·신고창 보존을 확인했습니다.
영웅 데이터와 메인·뉴비 페이지 응답이 v2.14.12와 동일함을 확인했습니다.
실제 브라우저 화면 렌더링 및 Cloudflare 운영 배포는 실시하지 않았습니다.

배포 후 확인
1. 영웅 상세 상단의 평가 기준 보기를 누르면 후기 위 범례로 이동하는지 확인합니다.
2. 4점 영웅은 4점 줄, 카산드라는 5점 줄이 금색인지 확인합니다.
3. 후기 작성란이 기존처럼 열리는지 확인합니다.
브라우저에 이전 페이지가 남아 있다면 강력 새로고침(Ctrl+Shift+R) 후 확인하세요.
