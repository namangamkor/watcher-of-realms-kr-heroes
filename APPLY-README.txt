나만겜 위키 v2.14.9 영웅 상세페이지 오류 수정

기준: v2.14.8 cursed-cult-gear-reaudit 패치

원인
- 상세페이지는 hero.portrait, memberships[].kr/en을 읽지만 실제 데이터는 memberships[].portrait, factionKr/factionEn을 사용하고 있었습니다.
- contentTags가 없는 213명은 .map() 호출에서 실행 오류가 발생했습니다.

수정
- 렌더링 직전에 데이터 구조를 맞추어 256명 전체에 적용했습니다.
- 초상화 경로를 사이트 루트 기준으로 변환했습니다.
- 콘텐츠 태그가 없으면 빈 배열로 처리합니다.
- 서비스워커 캐시 버전을 갱신했습니다.
- 영웅 데이터, 추천 장비, 아티팩트, 수집가치, 댓글 기능은 수정하지 않았습니다.

적용 방법
1. 기존 GitHub 사이트 저장소 최상위의 _worker.js와 sw.js를 이 ZIP 파일의 동일 파일로 덮어씁니다.
2. 커밋 후 기존 Cloudflare Pages 배포 완료를 확인합니다.
3. /hero/kassandra/ 와 /hero/abomination/ 을 새로고침해 확인합니다.
4. 이전 화면이 남으면 Ctrl+F5로 새로고침합니다. 응답 캐시 설정상 이전 페이지가 잠시 남을 수 있습니다.
이 파일은 변경 파일만 포함한 패치입니다. 단독으로 새 사이트를 배포하지 마세요.

검증
- 수정 전: 213개 실행 오류, 응답 가능한 43개 초상화 대체문자 표시.
- 수정 후: 256개 상세페이지 HTTP 200, 초상화 및 OG 이미지 경로, 한국/영문 진영명 검증 통과.
- 없는 영웅 404, 슬래시 주소 정규화 301, HEAD 응답 검증 통과.
- 운영 사이트 직접 조회는 연결 실패로 검증하지 못했습니다. 실제 이미지 파일 응답과 배포 후 화면은 미확인입니다.
