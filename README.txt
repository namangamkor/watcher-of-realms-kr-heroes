나만겜 위키 - 실전 딜 효율 연구소 BETA 0.1

1. 신규 페이지: damage-lab/index.html
2. 기존 GitHub 저장소의 루트에 damage-lab 폴더를 그대로 추가하면
   https://worwiki.kr/damage-lab/ 경로로 제공할 수 있습니다.
3. 메인 페이지의 링크/버튼을 추가하려면 최신 index.html을 확인한 뒤
   해당 파일의 실제 네비게이션 구조에 맞춰 아래 링크를 삽입하세요.
   <a href="/damage-lab/">실전 딜 효율 연구소</a>
4. 현재 ZIP에는 기존 index.html, app.js, styles.css, heroes.json,
   _worker.js, 서비스 워커 등의 기존 파일을 포함하지 않았습니다.
   기존 기능을 건드리지 않도록 새 경로만 제공하는 안전한 추가본입니다.
5. 직접 서버에 배포하거나 메인 링크를 수정하지는 않았습니다.
6. 계산기의 기본 지수는 공식 피해량이 아닙니다. 공속 보정과 방어력
   가정은 기본적으로 제외되어 있으며, 실험용 옵션으로만 사용합니다.
7. 실측값 6건은 사용자 제공 자료이며, 각 1회 전투 측정입니다.
