WoR Wiki v2.13.4l — 검색창 인지성 개선

목표
- 현재 아카이브/위키 미감을 유지하면서 검색 입력 영역만 더 명확하게 보이도록 개선

변경
- 기존 검색바 외형과 금색 포인트 유지
- 실제 입력 영역을 한 단계 안쪽의 남색 필드로 분리
- 검색바 전체 구조는 키우지 않음
- placeholder: “영웅 이름을 입력하세요 · 한국명 / 영문명 모두 검색 가능”
- 입력창 우측에 작은 “KR / EN” 보조표시
- 클릭/포커스 시에만 은은한 금색 강조
- 초기화 버튼은 검색어가 있을 때만 표시
- 모바일에서는 영웅 검색 라벨을 숨겨 입력칸 공간 확보
