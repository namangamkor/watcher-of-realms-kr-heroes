워처 오브 렐름 위키 v2.14.12 — 뉴비 영상·영웅 정렬 통합 수정

이 파일은 오늘 전달했던 버전 없는 뉴비 영상 패치와 영웅 정렬 패치를 대체합니다.
기준: 이전 전체본과 후속 패치 49개를 복원한 v2.14.11(장비 제목·여백 수정 포함).
전체 사이트 교체본이 아니라, 기존 사이트에 덮어쓰는 패치입니다.

적용
1. ZIP 압축을 풉니다.
2. 아래 파일·폴더를 GitHub 저장소 최상위에 올려 기존 파일을 덮어씁니다.
   _worker.js
   app.js
   index.html
   sw.js
   gear-detail-readable.css
   newbie/index.html
3. GitHub 변경을 커밋하면 기존 Cloudflare Pages 자동배포 절차가 실행됩니다.
4. 배포 성공 후 메인 화면과 /newbie/를 확인합니다.

중요: _worker.js가 있는 저장소 최상위에 적용해야 합니다.
newbie 폴더의 index.html을 최상위 index.html 대신 올리지 마세요.
ZIP 파일 자체를 업로드하는 것이 아니라 압축을 푼 파일들을 적용합니다.
기존 저장소 전체를 지우거나 영웅 데이터·이미지를 교체할 필요는 없습니다.
별도 Cloudflare 설정·환경변수·데이터베이스 변경은 없습니다.

변경 사항
- /newbie/: ‘한 줄로 먼저’와 같은 줄에 ‘나만겜 초보자 영상 가이드’ 링크 추가.
  https://youtu.be/Doe7uvPesXg
  화면이 좁으면 자연스럽게 줄바꿈됩니다.
- 전체 영웅 목록: 사용자 지정 46명을 맨 앞에 지정 순서대로 배치.
  어둠의 에지오 → 이비 프라이 → 바예크 → 에이보르 → 카산드라 → 에지오 아디토레부터 시작.
  우우는 루루로 반영했습니다.
- 검색 결과와 진영·희귀도·직업·콘텐츠·수집가치 필터도 같은 우선순위 유지.
- 지정하지 않은 영웅은 뒤에 원본 데이터 순서로 배치. 가나다순 정렬은 사용하지 않습니다.
  확인되지 않은 과거 업데이트 날짜·출시일을 만들어 넣지 않았습니다.
- Worker 내장 메인 HTML, 정적 index.html, app.js의 순서를 함께 갱신.
- 서비스워커 캐시 버전과 메인 app.js 참조 버전을 2.14.12로 갱신.
- 뉴비 HTML 응답은 재검증하도록 변경.
- 이전 장비 상세 오류 수정, 글씨 크기, 제목 여백 수정 유지.

적용 후 확인
- 메인 첫 6명이 위의 콜라보 영웅 순서로 표시되는지 확인합니다.
- ‘루루’ 검색 결과가 정상인지 확인합니다.
- /newbie/에서 영상 링크가 보이고 지정 YouTube 영상으로 연결되는지 확인합니다.
- 새 메인·뉴비 HTML 소스에는 worwiki-patch-version=2.14.12 표시가 있습니다.

검증 범위
- 복원한 수정 전 Worker의 메인·뉴비 응답이 작업 당시 운영 HTML과 바이트 단위로 일치.
- 복원한 app.js·styles.css가 작업 당시 운영 파일과 바이트 단위로 일치.
- 실제 수정 Worker 실행: 메인 정렬·뉴비 링크·GET/HEAD·리다이렉트·기존 데이터 접근 보호 통과.
- 영웅 상세 256개와 장비 프리셋 24개 응답은 수정 전 Worker와 동일.
- 실제 app.js 전체를 DOM 환경에서 실행: 초기 표시, 진영 10개, 필터 21개, 한·영 검색,
  루루 정정, 검색 결과 없음, 검색 해제, JS 미실행 시 기본 HTML 순서 검증 통과.
- 실제 Chrome의 화면 렌더링 검증은 실행하지 못했습니다(실행 파일 다운로드 불가).
- 운영 GitHub 업로드 및 Cloudflare 배포는 수행하지 않았습니다.
