# v2.11.24 · 파수꾼 게임 내 공식 특성 한국어 이식

기준본: v2.11.23 (관련 영상 링크 6명 변경)

## 변경 내용
- 파수꾼 40명 중 기존 공식 특성 보유 6명은 원칙적으로 유지
- 특성이 비어 있던 34명에 한국어 특성 추가
- 에이보르는 기존 비정규 표기 `공격 제어`를 공식 용어 사전에 맞춰 `방어 제거`로 정규화
- 한국어 표기는 사용자가 제공한 게임 내 공식 특성 용어를 사용
- 영웅별 대상 특성은 Prospector 최신 Role & Utility의 우선 표기(상위 핵심 항목)를 기준으로 대응했으며, 한국어 스크린샷으로 이미 확인된 기존 특성은 우선 보존
- `Defensive Dispel` → `공격 제거`는 고결 한국 서버 스크린샷으로 교차 확인된 대응을 사용
- `Offensive Dispel` → `방어 제거`로 대응
