# worwiki.kr v2.14.77 — 두 신규 영웅의 임시 운용 섹션 제거

- 기준 버전: v2.14.75 (사용자 배포 완료 확인). v2.14.76 배포는 확인되지 않아 그 수정도 포함한 누적 패치.
- 배포 상태: ZIP 제작 및 로컬 검증 완료. GitHub/Cloudflare 미적용.
- 원인: 전체 258명 중 오켄바르·베이라시아에만 `roleSummary`, `statPriority`, `statNote`가 존재해 `운용 · 장비 방향` 섹션이 생성되었다. 베이라시아의 `관통`, 오켄바르의 `피해 감소`를 존재하지 않는 장비 옵션처럼 적었다.
- 변경: 두 영웅에서 임시 운용 섹션 데이터를 제거하고, 해당 섹션 렌더러를 제거했다. 오켄바르 추천 장비 문장의 `권장 옵션`에서도 `피해 감소`를 제거한다(v2.14.76 수정 포함).
- 베이라시아 각성 A4의 `관통 +8%`, 오켄바르 각성 A4의 `모든 피해 감소 +8%`는 영웅 능력 문구로 유지한다. 다른 영웅의 상세 정보, 장비 세트 이름, 이미지, 최신 목록 순서는 변경하지 않았다.
- `_worker.js`, `app.js`, `heroes.json`을 함께 대조했고, 첫 화면의 앱 요청 버전도 v2.14.77로 올렸다.

## 적용

ZIP을 풀고 `_worker.js`, `app.js`, `heroes.json`, `index.html`, `README.md`, `VERSION.txt` 여섯 파일을 GitHub 저장소 루트에 같은 이름으로 덮어쓴다. ZIP 파일 자체는 업로드하지 않는다.

## 검증

v2.14.75와 비교한 영웅 데이터 변경 대상은 오켄바르·베이라시아 둘뿐이다. 258명 전체 Worker/JSON 정확히 일치, 임시 섹션 제거, 각성 문구 유지, 생성 스크립트 `--check`, JavaScript 문법 검사 통과.

삭제할 파일: 없음.
