# worwiki.kr v2.14.76 — 오켄바르 장비 옵션 문구 수정

- 기준 버전: v2.14.75 (사용자가 2026-09-28 배포 완료 확인)
- 현재 상태: 패치 ZIP 제작 및 로컬 검증 완료. v2.14.76은 GitHub/Cloudflare 미적용.
- 변경: 오켄바르 상세의 추천 스탯 목록에서 장비 옵션으로 존재하지 않는 `피해 감소`를 제거했다. 장비 추천 문장의 `권장 옵션`에서도 같은 항목을 제거했다.
- 영웅의 능력/각성에서 설명하는 피해 감소 효과(A4 `모든 피해 감소 +8%` 등)는 장비 옵션과 다른 정보이므로 유지했다. 장비 세트 이름과 나머지 옵션은 변경하지 않았다.
- `_worker.js`의 영웅 데이터와 `heroes.json`을 정확히 일치시켰고 `app.js` 및 첫 화면의 요청 버전을 v2.14.76으로 올렸다. `index.html`에도 같은 요청 버전을 반영했다.

## 적용

이 ZIP의 `_worker.js`, `app.js`, `heroes.json`, `index.html`, `README.md`, `VERSION.txt` 여섯 파일을 GitHub 저장소 루트에서 같은 이름으로 덮어쓴다. ZIP 자체는 올리지 않는다. 다른 파일은 업로드하지 않는다.
