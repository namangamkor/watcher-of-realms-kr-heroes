## 변경 내용

- 그웬돌린 영웅 이미지를 사용자가 첨부한 WebP로 교체했습니다.
- 새 파일명: `north-throne-hq-12-gwendolyn-v214157.webp`.
- 원본 600×895 이미지의 바이트를 그대로 사용했습니다. 재생성·재압축·자르기를 하지 않았습니다.
- 수집가치를 3.0에서 4.0으로 상향했습니다.
- 상향 사유: **장비지하성 3·타천의 쌍둥이 던전에서의 활용도 상승.**
- 사유를 기존 수집가치 평가 사유 항목에 등록하여 상세페이지에서 4.0점과 함께 표시합니다.
- 이미지·수집가치 평가의 확인일과 정보 업데이트 기록을 2026-10-20으로 등록했습니다.
- 메인 카드·상세 이미지·공유 이미지 경로를 새 이미지로 연결했습니다.
- 메인 카드의 기존 크기는 유지하면서 그웬돌린 이미지의 전체 테두리가 보이도록 해당 카드에만 맞춤 표시를 적용했습니다.
- 최근 업데이트와 초기 메인 목록에 그웬돌린 변경을 반영했습니다. 다른 영웅의 상대적인 기본 순서는 보존했습니다. 실제 운영에서는 더 최근에 공개된 후기가 있으면 기존 활동 정렬 규칙을 따릅니다.
- `_worker.js` 내장 데이터, `heroes.json`, `app.js`, 정적 메인과 캐시 버전 참조를 함께 동기화했습니다.

평가 점수와 사유의 출처는 사용자 확정 지시이며, 첨부 이미지는 사용자가 제공한 최종 자산입니다. 기존 각성·스킬·장비·아티팩트의 검증일을 새로 확인한 것으로 바꾸지 않았습니다.
