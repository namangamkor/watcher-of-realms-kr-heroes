## 이번 변경
- `오늘의 운명 시험 초기화` 버튼을 BGM ON 버튼과 동일한 청회색 계열 UI로 통일.
- 오켄바르가 메인에는 등록됐지만 검색에서 나오지 않던 문제 수정.
- 원인: 검색/필터가 사용하는 `/heroes.json`은 Cloudflare 정적 자산의 기존 256명 데이터를 계속 반환하고 있었음.
- 수정: `/heroes.json` 응답 시 현재 `_worker.js`의 `HEROES`에 있는 신규 영웅을 기존 JSON 구조에 자동 병합.
- 이후 `_worker.js`에 신규 영웅을 추가하면 검색 데이터에도 자동 편입되도록 재발 방지.
- 기존 소환 확률, 30/50회 운명시험, 10초 효과음, BGM, 오켄바르 상세정보 유지.
