## 주요 변경
- app.js에 defer 적용: 안내창 DOM 생성 이후 실행하여 showModal null 오류 수정.
- CSS 캐시 버전 갱신: 안내창 스타일 반영.
- 이미 특성이 선택된 상태에서 다른 특성을 누르면 추가 선택 / 새로 선택 안내창 표시.
- 추가 선택은 기존 선택 유지, 새로 선택은 방금 누른 특성만 선택.
- 선택 해제·전체는 즉시 적용. 취소·Esc는 기존 선택 유지.
- 기본 dialog로 키보드 포커스와 화면 배경 접근 제어.
- 메인페이지 수집가치 아래 영웅특성 버튼 27종 추가.
- 기존 공식 특성 표기와 원본 데이터 유지. 비교할 때만 공백 무시.
- 여러 특성은 모두 충족하는 영웅 검색. 다시 누르면 해제, 전체 및 기존 초기화 버튼 연결.
- 진영·희귀도·직업·콘텐츠·수집가치와 조합, 더 보기 연결.
- Worker 홈 HTML 동기화 및 캐시 버전 갱신.
- 기존 v2.14.93 누적 파일 포함.

## 적용
ZIP을 풀고 내부 파일을 기존 GitHub 저장소의 같은 경로에 덮어쓴 뒤 기존 방식으로 배포하세요. 전체 사이트 백업이 아니므로 기존 파일을 삭제하지 마세요. ZIP 자체를 저장소에 올리지 마세요.
