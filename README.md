## 반영 내용

황혼 그림자의 칼날(The Grey Blades) 진영을 영웅도감 필터에 추가하고, 전설 영주 궁수 **아멜리아(Amelia Ainsworth)**를 등록했습니다. 전체 영웅은 **258명 → 259명**, 진영 선택은 기존 10개 → 11개입니다. 신규 진영의 현재 등록 영웅은 아멜리아 1명입니다.

사용자가 제공한 600×800 WebP 초상화를 원본 바이트 그대로 사용합니다. 목록·간략 보기·상세페이지에서 같은 파일을 참조합니다.

상세페이지에는 영주 스킬 **황혼 그림자의 검 III**, 재능, 물리 공격, 진홍 관통 사격, 폐막의 추징, 암막의 합주, 침묵의 해부와 추격 연계 효과·각성 A1~A5를 등록했습니다. 진영 이름과 영주 스킬 이름은 첨부 자료의 서로 다른 표기를 각각 유지합니다.

아멜리아의 등록 시간을 정보 업데이트 시간으로 기록했습니다. 홈 업데이트 목록과 영웅목록 모두 최근 활동순으로 정렬하므로 아멜리아가 먼저 표시되며, 이후 새로 공개되는 후기도 기존 규칙대로 정렬에 반영됩니다. 업데이트 문구는 20자 이내입니다. 최초 20명 로딩, 더 보기, 상세/간략 보기와 기존 필터를 유지합니다.

아멜리아 수집가치는 **평가 준비 중**으로 표시하며, 추천 장비·아티팩트는 미등록 상태입니다. 특성 필터용 분류는 첨부 스킬 설명을 근거로 등록하고, 상세페이지에는 ‘영웅 특성’으로 표시합니다.

기존 258명의 데이터와 v2.14.116 오켄바르 `강철 의지 = Tempered Will` 교정을 유지했습니다. 가로크는 이번 패치의 등록 대상에 포함하지 않았습니다.
