- 현재 패치 버전: **v2.14.145**

- 작업일: 2026-10-18 (Asia/Seoul)
- 제작 상태: 완료 — 소개 48종, 영문명 확인 47종 / 확인 보류 1종

## 변경사항

`/demon-soldiers/`에 마법병사 소개페이지를 추가했습니다. 제공된 한국 서버 게임 화면 48장을 기준으로 마법 장군 5종, 레전더리 16종, 에픽 27종을 등록했습니다. 메인 화면의 바로가기 영역에 **마법병사 도감 · 한영 이름**을 연결했습니다.

각 카드에는 한국어 이름, 확인된 영문명, 게임 이미지, 소개, 생물 특성, 주요 기능, 에너지·수량·장갑을 표시합니다. 카드를 펼치면 촬영 레벨, 공격력·HP·방어력·마법 저항·속도 등급과 화면에 보이는 대표 스킬의 이름·사용 유형, 횟수 제한을 확인할 수 있습니다.

- 한글·영문 이름과 소개·특징 검색. 이름의 띄어쓰기·대소문자를 구분하지 않습니다.
- 등급, 생물 특성, 주요 기능, 장갑 필터를 함께 적용할 수 있습니다.
- 등록 순, 한글 이름순, 영문 이름순, 에너지 낮은 순 정렬. 등급별 묶음은 유지합니다.
- 검색 조건을 주소에 유지하고, 카드의 `#` 링크로 해당 항목을 바로 열 수 있습니다.
- 자바스크립트 없이도 전체 48종의 소개와 펼침 항목이 표시됩니다.
- PC 3열, 태블릿 2열, 작은 모바일 화면 1열의 반응형 구성을 적용했습니다.
- 원본의 중앙 캐릭터 영역을 WebP 이미지 48개로 정리했습니다.
- 제목·설명·공유 메타 정보, 구조화 데이터, 사이트맵 연결을 추가했습니다.

## 한영 이름과 자료 기준

한글명은 제공된 게임 화면 표기를 그대로 사용합니다. 영문명은 Fastidious, Watcher of Realms Wiki 및 Dan Heilman 자료에 나오는 명칭·역할·속성 정보를 대조했습니다. 외부 자료와 분류가 다른 항목의 희귀도·생물 특성·능력치는 한국 서버 화면을 기준으로 합니다.

직역과 다른 명칭의 예:

| 한국 서버 이름 | 대조한 영문명 |
| --- | --- |
| 워록 | Shadowcaster |
| 도끼 버처 | Axe Slaughterer |
| 뒤틀린 혀 | Murkling Menace |
| 스켈레톤 레인저 | Soulbone Archer |
| 프로즌 레인저 | Frozen Drifter |
| 서리 투창수 | Frozen Raider |
| 연옥 제사장 | Infernal Cleric |
| 열등한 악마 | Grotesque Fiend |

**폭발 좀비는 동일 개체의 영문명을 확인하지 못했습니다.** 해당 항목은 한국어 이름과 화면 정보로 등록하고 “영문명 확인 중”으로 표시했습니다. 임의 번역을 영문명으로 확정하지 않았습니다.

고급 심연의 눈은 `High-order Abyssal Beholder`로 표시하며, 해외 자료에서 쓰는 `Abyssal Beholder`로도 검색됩니다. 빙혈 학자는 `Frostbourne Scholar`로 표시하고 `Frostborne Scholar` 검색도 지원합니다.

등록 범위는 제공된 48종입니다. 현재 게임 전체 마법병사 목록을 의미하지 않습니다. 수량·횟수 제한·능력치 등급은 각 화면의 촬영 레벨 기준이며 강화나 업데이트에 따라 달라질 수 있습니다. 주요 기능은 소개문을 바탕으로 정리한 검색용 분류입니다. 대표 스킬의 상세 계수와 레벨별 성장 조건은 이번 화면에 없으므로 포함하지 않았습니다.

## 포함 파일과 적용

ZIP을 풀어 **65개 파일을 저장소 루트에 함께 업로드**하고 같은 이름의 파일을 덮어씁니다. 기존 저장소의 다른 파일은 유지합니다.

- `_worker.js`, `app.js`, `heroes.json`: 반드시 한 세트로 적용합니다.
- `index.html`: 메인의 마법병사 소개페이지 진입 링크.
- `demon-soldiers.html`, `demon-soldiers.json`: 소개페이지와 48종 데이터.
- `demon-soldiers-v214145.css`, `demon-soldiers-v214145.js`: 소개페이지 스타일·검색·분류 기능.
- `demon-…-v214145.webp` 48개: 마법병사 이미지.
- 기존 아티팩트 검색·프리셋·로케쉬 관련 파일: v2.14.144 내용 유지.
- `README.md`, `VERSION.txt`: 이번 변경·버전·배포 상태.

v2.14.143의 로케쉬 신규 등록·수집가치 3.0과 v2.14.144의 관련 영상 연결을 포함하는 누적 패치입니다. 영웅 261명의 데이터와 기존 관련 영상은 보존했습니다. DB 변경이나 환경변수 추가는 필요하지 않습니다.

정상 주소는 `/demon-soldiers/`입니다. `/demon-soldiers`, `/demon-soldiers.html`, `/demon-soldiers/index.html` 접근은 검색 조건을 유지하며 정상 주소로 이동합니다. Worker의 내장 HTML·JSON과 정적 파일을 함께 갱신했습니다.
