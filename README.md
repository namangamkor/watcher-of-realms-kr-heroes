# v2.14.153 북키퍼 추천 추가

- 현재 패치: v2.14.153
- 기준 버전: v2.14.152
- 수정일: 2026-10-19 (Asia/Seoul)
- 실제 사이트 적용: 미확인

## 변경 사항

북키퍼를 적이 밀집한 방어 배치를 공략하는 조건부 추천으로 추가했습니다.
추천 이유·사용 조건·접을 수 있는 근거를 기존 카드 배치에 맞춰 표시합니다.
추천 수는 11종에서 12종으로 변경했으며 추천 필터와 검색에도 반영했습니다.

북키퍼의 근거는 사용자가 제공한 한국 서버 6레벨 게임 화면의 역할 설명입니다.
해외 커뮤니티 추천으로 표시하지 않았으며 확인하지 않은 추가 스킬·해금 레벨·피해 수치는 넣지 않았습니다.
전체 추천 기준에는 해외 실전 의견과 게임 화면을 바탕으로 한 편집 추천이 함께 있음을 명시했습니다.

## 적용

v2.14.152에 ZIP의 10개 파일을 저장소 루트에 함께 덮어씁니다.
필수 동기화 세트 _worker.js·app.js·heroes.json과 메인 HTML, 마법병사 HTML·JSON·JS·CSS, README·VERSION을 포함합니다.
추가·변경된 WebP는 없습니다. 기존 카드 이미지와 v2.14.152 타이틀 이미지를 계속 사용합니다.

마법병사 53종·개편 예고 7종·영웅 261명과 기존 추천 11종의 개별 내용은 유지했습니다.
JSON·HTML·Worker 내장본의 추천 내용과 수량, 추천 필터·검색·주소 복원, 홈 24개 로드와 영웅 목록 일치를 검사했습니다.
브라우저 시각 검수와 실제 배포는 수행하지 않았습니다.
