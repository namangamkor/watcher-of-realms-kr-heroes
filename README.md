# v2.14.154 마법병사 이름 검색 수정

- 현재 패치: v2.14.154
- 기준 버전: v2.14.153
- 수정일: 2026-10-19 (Asia/Seoul)
- 배포 상태: 패치 제작 완료 / 실제 사이트 미배포

## 수정 내용

기존 검색은 추천 이유와 사용 조건까지 포함해, ‘열등’을 검색하면 ‘열등한 악마’를
언급하는 슬로터·그레시우스 등 7종이 함께 표시됐습니다.
추천 이유·조합 설명을 검색 대상에서 제외해 ‘열등’과 ‘열등한 악마’ 검색에는
열등한 악마만 표시되도록 수정했습니다.

한국명·영문명·영문 별칭과 해당 병사의 생물 특성·장갑·기능·소개·대표 스킬은
계속 검색할 수 있습니다. 추천 분류명 검색과 기존 필터도 유지합니다.

## 적용 방법

v2.14.153에 ZIP의 10개 파일을 저장소 루트에 함께 덮어씁니다.
필수 동기화 세트인 _worker.js·app.js·heroes.json을 포함합니다.
HTML과 JS·CSS의 버전 참조를 v2.14.154로 맞췄습니다.
추가 WebP는 없습니다. 기존 카드·타이틀 이미지를 계속 사용합니다.

마법병사 53종, 추천 12종, 개편 예고 7종, 영웅 261명의 기존 내용은 유지했습니다.

- 기존 ‘열등’ 검색에서 추천 병사 7종이 표시되는 문제 재현 후 1종으로 수정 확인.
- 마법병사 53종의 한국명·영문명·별칭과 특징 검색, 추천 12종·등급 필터 검증.
- PC 및 모바일 Chromium에서 한글 조합 입력(IME), 영문 입력, 빈 결과, 초기화, 주소 복원·새로고침 검증.
- Worker 응답과 정적 HTML·JSON 일치 및 영웅 261명·정렬 순서 보존 확인.
- 실제 운영 사이트 배포는 수행하지 않았습니다.
