## 변경 사항

1. 최초 영웅 표시와 더 보기 증가량을 모두 20명에서 24명으로 변경했습니다. 24 → 48 → 72명 순으로 표시하며 마지막에는 남은 영웅만 추가합니다.
2. Worker의 첫 화면, index.html의 기본 목록·표시 수, app.js의 목록 로딩을 같은 24명 기준으로 맞췄습니다.
3. 화면 너비 620px 이하에서는 영웅특성 버튼을 줄바꿈해 끝 버튼이 잘리는 가로 스크롤을 없앴습니다.
4. 모바일 특성 영역 아래 여백은 20px, 보기 선택과 영웅 카드 사이 여백은 16px로 정리했습니다.
5. CSS·앱·데이터 요청의 버전을 갱신해 이전 캐시가 남아 있는 경우에도 새 화면을 받도록 했습니다.
6. 320px처럼 좁은 화면에서는 초상화가 카드 너비에 맞게 비율을 유지해 줄어들도록 해 목록의 가로 넘침도 정리했습니다.
