# worwiki.kr v2.14.79 — 베이라시아 영문명 수정

- 기준 버전: 사용자가 배포 완료를 확인한 v2.14.75. v2.14.76~v2.14.78의 배포 확인이 없어 해당 수정도 포함한 누적 패치.
- 배포 상태: 패치 ZIP 제작 및 로컬 검증 완료. GitHub/Cloudflare 미적용.
- 사용자가 확인한 정확한 영문명 `Veyrathia`로 베이라시아의 표시명·검색 데이터·상세 정보·첫 화면 카드를 동기화했다. 기존의 `Beirasia` 임시 표기 문구를 제거했다.
- `/hero/beirasia/` 주소와 이미지 파일명은 그대로 유지한다. 기존 링크와 이미지 경로가 끊기지 않도록 내부 ID는 변경하지 않았다.
- v2.14.78에 포함된 베이라시아 추천 장비 `악의 복수 + 재앙 드래곤`, 두 영웅에게만 임의로 추가한 ‘운용 · 장비 방향’ 섹션 제거, 오켄바르의 잘못된 권장 옵션 `피해 감소` 제거도 포함한다.
- 각성 A4 효과(베이라시아 `관통 +8%`, 오켄바르 `모든 피해 감소 +8%`)는 그대로 유지한다.

## 적용

ZIP을 풀어 `_worker.js`, `app.js`, `heroes.json`, `index.html`, `README.md`, `VERSION.txt` 여섯 파일을 GitHub 저장소 루트에 같은 이름으로 덮어쓴다. ZIP 자체는 업로드하지 않는다.

## 검증

v2.14.75 대비 변경된 영웅 데이터는 오켄바르·베이라시아 둘뿐. Worker/JSON 258명 데이터 완전 일치, 첫 화면 카드 영문명 Veyrathia, 기존 상세 주소 유지, 생성 스크립트 동기화 및 JavaScript 문법 검사 통과.

삭제할 파일: 없음. 기존 이미지 파일명에 `beirasia`가 들어가도 경로가 사용 중이므로 삭제하거나 이름을 바꾸지 않는다.
