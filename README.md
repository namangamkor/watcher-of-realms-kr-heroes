## 변경사항

1. 로케쉬(Rorkesh), 황혼 그림자의 칼날 소속 전설 궁수를 추가했습니다.
2. 제공된 한국어 게임 화면 기준으로 공식 특성 5개, 재능·일반 공격·궁극기·패시브 2개, 각성 A1~A5를 정리했습니다. 스킬 수치는 최대 레벨 기준이며 각성 효과를 기본값에 섞지 않았습니다.
3. 제공된 초상화를 전체 프레임이 보존되도록 597×840 WebP로 변환했습니다. 목록과 상세페이지에서 동일한 파일을 사용합니다.
4. 기존 상세페이지의 소개·진영·추천 장비·추천 아티팩트·각성·후기·프리셋·오류 제보 구성을 유지했습니다. 스킬 상세 블록은 `details.showSkills`를 켠 로케쉬에만 추가됩니다.
5. 전체 고유 영웅 260→261명, 황혼 그림자의 칼날 2→3명, 최신 업데이트 및 메인 기본 순서를 동기화했습니다. 새 후기가 등록되면 기존 활동 날짜 정렬 규칙을 그대로 따릅니다.
6. 추천 장비는 악의 복수 + 재앙 드래곤, 범용 아티팩트는 망령술사의 손가락을 공개 빌드 참고 후보로 등록했습니다. 한국명과 아이콘은 기존 위키의 검증된 한영 매칭을 사용합니다. 수집가치는 사용자 확정 평가 3.0으로 반영했습니다. 목록과 상세페이지가 같은 값을 사용합니다.
7. 아티팩트 검색에 로케쉬를 연동했습니다. `/hero/rorkesh/`의 기본 SEO·canonical·구조화 데이터는 기존 상세페이지 생성기를 사용하며, `/sitemap.xml` 응답에는 기존 URL을 보존하면서 새 주소를 한 번만 추가합니다.

## 자료 및 기준

- 한국어 명칭·특성·스킬·각성: 사용자가 제공한 게임 화면 13장 및 초상화 1장.
- 영문명·진영 교차 확인: [Fastidious](https://fastidious.gg/), [SimiPRO 로케쉬](https://simipro.gg/heroes/rorkesh).
- 장비 및 아티팩트 참고: [AllClash 로케쉬 공개 빌드](https://www.allclash.com/best-build-for-rorkesh-in-watcher-of-realms-gear-stat-prio-artifact-awaken-prio/). 장비던전 22~24단계 추천을 참고했습니다. 장비 조합을 실측한 최적 세팅으로 표시하지 않습니다. 수집가치는 2026-10-17 사용자가 직접 확정한 3.0입니다.
- 한국어 게임 화면과 해외 DB의 초기 스킬 레벨·궁극기 조작 방식이 다른 경우 제공된 화면을 우선했습니다. 궁극기는 자동, 분노 소모 350, 피해 800%, 일반 공격 140%, 중탄 발동 확률 50%를 사용했습니다.
- 추천 콘텐츠, 소환 이력, 관련 영상은 확인된 추가 자료 없이 임의로 등록하지 않았습니다.

## 포함 파일과 적용 방법

ZIP 안의 13개 파일을 폴더 없이 저장소 루트에 업로드하고 같은 이름의 파일은 덮어씁니다. 전체 백업이 아닌 패치이므로 기존 나머지 파일은 유지합니다.

- `_worker.js`, `app.js`, `heroes.json`: 반드시 같은 커밋에 함께 적용.
- `index.html`: Worker 메인과 동기화한 정적 메인.
- `artifacts.html`, `artifacts.json`: 로케쉬를 추가한 아티팩트 검색.
- `grey-blades-hq-03-rorkesh-v214143.webp`: 로케쉬 초상화.
- `hero-skills-v214143.css`: 선택적으로 표시하는 스킬 영역 스타일.
- `gear-presets.html`, `preset-growth-v214140.webp`, `preset-end-v214140.webp`: v2.14.142의 승인된 프리셋 선택 화면과 이미지, 내용 그대로 동봉.
- `README.md`, `VERSION.txt`: 패치 버전·기준 버전·변경 및 배포 상태.

기존 후기 DB, 관리자 설정, 댓글 스크립트, 공통 스타일 및 다른 영웅 이미지는 그대로 사용합니다. DB 마이그레이션이나 새 환경변수는 필요하지 않습니다.
