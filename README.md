# 워처 오브 렐름 위키 v2.14.112

- 현재 패치: v2.14.112
- 기준 버전: v2.14.111
- 제작 및 코드 검증: 완료
- 실제 사이트 적용·배포: 미실시
- 실제 PC·모바일 브라우저 렌더 검증: 미완료. 검증용 브라우저 설치가 실패했고 별도 미리보기 브라우저가 로컬 서버에 연결되지 않았습니다.

## 변경 내용

메인페이지 CSS 정리 1차 패치입니다. 메인페이지에 흩어진 인라인 스타일을 `home-layout.css`로 이동했습니다. 업데이트 목록의 과거 CSS 규칙 35개를 공통 `styles.css`에서 제거하고 전용 파일에 통합했습니다. 영웅특성도 이전 한 줄 배치·점선 버튼·제목 배치 규칙을 제거하고 현재 구조에 맞는 한 세트의 규칙으로 정리했습니다.

업데이트 목록은 유형·영웅명·짧은 설명·날짜의 그리드 배치를 사용합니다. 좁은 화면에서는 영웅명과 설명이 말줄임되고 날짜는 같은 행 오른쪽에 표시됩니다. 영웅특성 제목 옆 펼침/접기 버튼은 스크롤 영역 밖에 유지하고, 기본 특성은 한 줄 가로 스크롤, 펼치면 전체 특성 줄바꿈을 유지합니다. 모바일 펼침/접기 터치 높이 44px를 유지합니다.

큰 제목·제작자 소개 압축과 검색 조건 요약은 이번 범위에 포함하지 않았습니다. 영웅 데이터·이미지·정보 수정일·업데이트순 정렬은 그대로입니다.

## 적용

v2.14.111이 적용된 저장소 기준으로 아래 다섯 파일을 루트에 반영한 뒤 기존 GitHub/Cloudflare 배포 방식으로 배포하세요. 새 `home-layout.css`도 반드시 추가해야 합니다.

- index.html
- app.js
- _worker.js
- styles.css
- home-layout.css (신규)

index와 Worker에 포함된 홈 HTML이 같은 스타일 파일을 참조하도록 동기화했고, 메인페이지 CSS와 앱 캐시 쿼리를 v2.14.112로 변경했습니다. 이 ZIP은 변경 파일만 제공하며 전체 백업이 아닙니다. 별도 영웅 이미지나 heroes.json 교체는 없습니다.

## 검증 결과와 제한

258개 영웅의 Worker 내장 데이터 불변, Worker 홈 HTML과 index 일치, 업데이트 API 및 초기 영웅 카드 순서 불변을 확인했습니다. app.js는 캐시 버전 외 변경이 없습니다. 기존 코드를 실행하는 제어된 DOM 테스트에서 특성 펼치기/접기, 선택 유지, 추가 선택, 새로 선택, 취소, 전체 초기화 및 복수 특성 AND 검색을 확인했습니다. JavaScript 문법 검사가 통과했습니다.

위 테스트는 실제 브라우저 렌더 검증을 대체하지 않습니다. 적용 뒤 PC 및 모바일에서 업데이트 한 줄·날짜 위치, 영웅특성 기본 한 줄·가로 스크롤·펼침/접기, 중복 선택 팝업, 초기화 및 최신 업데이트순 정렬을 확인해야 합니다. 이번 패치는 메인 업데이트 목록과 영웅특성의 CSS 정리가 중심이며 사이트 전체 CSS 리팩터링 완료를 의미하지 않습니다.
