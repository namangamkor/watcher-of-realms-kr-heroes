## 이번 변경

### 1. 소환 수정 비주얼 경량화 + 모바일 강화
- 실제 입체감 있는 수정 이미지를 사용.
- 소환 수정은 천천히 부유/회전하고, 외곽 금속 링은 별도로 회전.
- 모바일에서 수정/링 크기를 확대해 존재감을 강화.
- 라이브 자산을 PNG에서 WebP로 변경.
  - 수정: 약 1.1MB PNG → 약 224KB WebP
  - 오켄바르 초상: 약 73KB PNG → 약 10KB WebP
- 이전 수정 PNG는 `BACKUP_summon-crystal-3d-v2.14.36.png`로 백업 유지.

### 2. BGM ON/OFF 버튼
- 소환 페이지 배경음악 기본 ON.
- 볼륨 30%.
- 반복 재생(loop).
- `♫ BGM ON / OFF` 버튼 추가.
- BGM ON/OFF 선택은 소환 결과/일일 통계와 별도로 저장하지 않으며, 페이지를 다시 열면 기본 ON.
- 브라우저 자동재생 정책상 실제 소리는 첫 클릭/터치/키 입력 후 시작.

### 3. 오켄바르(Oakenvar) 보강
- 영문명/라우트 `Oakenvar`, `/hero/oakenvar/`로 교정.
- 전설 수호자 / 파수꾼 소대.
- 사용자 제공 게임 내 스크린샷 기준 A1~A5 정보 유지.
- 추천 장비: `성흔의 수호 (Astral Guardian) + 강철 의지 (Unshaken Will)`.
- 추천 아티팩트: `보루의 반지 (Bastion Ring)`.
- 신규 영웅 추가 후 도감 총 257명.

### 4. 운명시험 초기화 UI
- 밑줄 TEXT 형태에서 실제 보조 버튼으로 변경.
- 표시: `↻ 오늘의 운명 시험 초기화`.
- 기존의 “운명을 거스르겠습니까?” 확인창은 그대로 유지.

### 5. 기존 기능 유지
- 1명 / 10명 소환.
- 전설 총확률 1%, 에픽 21%, 레어 78%.

- 30회 체크포인트 → 선택 시 50회까지.
- 다음 날 자동 초기화.
- 최종 통계 보고서.
- 소환 효과음 유지.
