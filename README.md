## 포함 파일 및 적용

ZIP의 13개 파일을 저장소 루트에 함께 업로드하고 같은 이름의 파일을 덮어씁니다. 기존 나머지 파일은 유지하세요. v2.14.143의 로케쉬 추가 내용이 포함된 누적 패치이므로 이전 파일과 섞지 않고 이 ZIP을 적용합니다.

- `_worker.js`, `app.js`, `heroes.json`: 반드시 한 세트로 적용합니다.
- `index.html`: 최신 영상 업데이트 및 활동 기록을 반영한 정적 메인.
- `artifacts.html`, `artifacts.json`: v2.14.143의 로케쉬 아티팩트 검색 연결 유지.
- `grey-blades-hq-03-rorkesh-v214143.webp`, `hero-skills-v214143.css`: 로케쉬 이미지와 스킬 표시 스타일 유지.
- `gear-presets.html`, `preset-growth-v214140.webp`, `preset-end-v214140.webp`: 승인된 프리셋 선택 화면 유지.
- `README.md`, `VERSION.txt`: 이번 패치 버전·기준·변경 및 배포 상태.

DB 변경이나 환경변수 추가는 필요하지 않습니다. 기존 후기·추천 장비·추천 아티팩트·필터·페이지 구성을 유지합니다.
