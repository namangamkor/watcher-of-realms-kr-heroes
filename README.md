## 원인

서버의 초기 목록은 index.html에 남아 있던 카드와 간소한 대체 카드를 섞어 보여주었습니다. app.js는 데이터 로딩 후 카드 24개를 모두 다시 만들었습니다. 이 때문에 수집가치 아이콘·영주/이중 진영 표시·활동 표시가 달라지고 이미지가 다시 로딩되는 구간이 있었습니다.

보기 버튼도 앱 실행 전에는 숨겨져 있어 모바일에서 로딩 전후 목록 위치가 68px 이동했습니다. sw.js에는 v2.14.21 앱 등 예전 캐시 목록이 남아 있었습니다. 캐시 문제만으로 원인을 설명하지 않고 초기 HTML과 앱의 카드 구성을 함께 수정했습니다.

## 변경 사항

1. _worker.js와 index.html의 초기 카드에 앱과 동일한 수집가치 아이콘, 영주·희귀도·이중 진영, 활동, 콘텐츠 표시를 적용합니다. 최신 후기 때문에 기본 24명 밖의 영웅이 앞으로 올라와도 같은 카드로 표시합니다.
2. app.js는 내용이 같은 기존 카드와 이미지 요소를 유지합니다. 초기 로딩과 더 보기에서 기존 목록을 통째로 교체하지 않습니다.
3. 상세 보기·간략 보기 버튼을 초기 HTML부터 표시하고 사용할 수 있게 합니다. 저장된 보기 방식과 선택 표시도 처음부터 일치합니다.
4. 후기 API 요청이 실패하면 서버가 이미 표시한 활동 정보와 정렬을 유지합니다.
5. sw.js 캐시 이름과 앱·홈 CSS 주소를 갱신하고, 영웅 데이터와 후기 API는 네트워크에서 최신 응답을 받습니다. 홈 CSS와 활동 CSS에도 최신 응답 우선 정책을 적용합니다.

260명 영웅 데이터, 11개 진영, 24명씩 더 보기, 모바일 특성 영역 배치, 가로크 새 초상화, 기존 상세페이지 구성은 유지합니다. heroes.json은 기준 버전과 바이트가 같습니다. home-layout.css는 모바일 개선본을 함께 포함하며 버전 안내 주석을 추가했습니다.
