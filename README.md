# 나만겜 위키 v2.14.191 — 멜리사라 초상화 교체
기준 버전 v2.14.186. v2.14.187~190 변경사항 포함. 작성 2026-11-28.

멜리사라 목록·상세 초상화를 사용자 제공 얼굴 확대 이미지로 교체했습니다.
원본 비율·프레임을 유지해 WebP로 변환했습니다.
에테리온·멜리사라 신규 정보와 수집가치·영상·소환 이력, 키기리 200회 확정 소환 이력을 포함합니다.

## 적용
_worker.js와 heroes.json을 루트에 덮어쓰고 포함된 WebP 2개를 루트에 추가합니다.
v2.14.186에서 바로 적용하거나 v2.14.190에 덮어쓸 수 있습니다.
README.md와 VERSION.txt는 버전 기록입니다.

검수 · 이미지 경로 동기화 및 멜리사라 상세페이지 참조 확인.
배포 상태 · 패치 작성, 사이트 미배포.
