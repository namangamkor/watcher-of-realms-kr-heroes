# worwiki v2.14.138 — 아티팩트 통합 검색

- 기준 버전: v2.14.137. 누적 덮어쓰기 패치.
- 업데이트: 2026-10-14 (한국시간)
- 배포/적용: 배포 미실행. GitHub 업로드 후 적용.
- 메인 소환 운명시험 고정 버튼을 아티팩트 검색 버튼으로 교체. 기존 소환 페이지 유지.
- /artifacts/ 페이지: 기존 데이터 128종의 한국명·영문명·추천 영웅명 통합 검색.
- 전용/범용 필터, 검색 초기화, 결과 없음 안내, 모바일 한 열·웹 두 열 레이아웃.
- 영웅 상세 추천 아티팩트에서 검색 결과로 바로 연결.
- 추천 영웅은 실제 등록된 추천 관계이며 모든 장착 가능 영웅이나 직업을 의미하지 않음.
- 기존 배포된 아티팩트 아이콘 파일을 재사용. 이미지 미로딩 시 깨진 이미지 대신 간단한 심볼 표시.
- 영문 누락 구형 보조 필드는 임의 매칭하지 않음. 게임 전체 아티팩트 완전 목록을 보장하지 않으며, 현재 확인된 한·영 이름 128종 수록.
- v2.14.137 아멜리아 장비추천·두 영웅 영상·수집가치 4 및 베이라시아 패치 유지.

적용: ZIP 전체를 기존 저장소에 덮어쓰기 업로드. _worker.js·app.js·heroes.json 동시 반영. artifacts.html과 artifacts.json 포함. 기존 아티팩트 이미지 파일은 유지.
검증: 128종 한·영 이름 완전 매칭, 검색·필터·빈 결과·직접 링크 로직, Worker 페이지·리다이렉트·영웅 상세 링크·메인 버튼, JS 구문 검사, 기존 영웅 데이터 검증 통과.
제한: 브라우저 실행 환경 준비 실패로 실제 모바일/웹 시각 검수 미완료. 실사이트 배포 미실행.
