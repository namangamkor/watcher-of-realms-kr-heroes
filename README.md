# 나만겜 워처오브렐름 위키 패치

## 현재 패치 버전
**v2.14.29**

## 기준 버전
**v2.14.28 소환 확률 적용 패치**

## 이번 변경
- 소환 미니게임을 `1명 소환` / `10명 소환` 두 방식으로 확장
- 10명 소환 결과는 PC에서 **5명 × 2줄**로 표시
- 태블릿에서는 3열, 모바일에서는 2열로 자동 재배치
- 10명 결과의 각 영웅 카드를 누르면 해당 영웅 상세페이지로 이동
- 1명/10명 모두 같은 기존 확률표와 `crypto.getRandomValues()` 추첨 로직 사용
- 10명 소환은 10번의 독립 추첨이므로 동일 영웅 중복 등장 가능
- 소환 버튼을 누른 뒤 약 2.25초 연출 유지
- 외부 음원 파일 없이 Web Audio API로 짧은 소환 테마음을 실시간 생성
- 1명 소환과 10명 소환의 음 진행을 약간 다르게 구성
- 브라우저가 Web Audio를 지원하지 않아도 소환 기능 자체는 정상 동작
- 로그인/DB/LocalStorage/소환 이력 저장 없음
