## 이번 변경
- 미니게임 제목: **오늘 당신의 소환 운명을 시험해보시겠습니까?**
- 사용자가 제공한 소환 효과음 기반 `summon-effect.m4a` 유지
- 매일 브라우저 현지 날짜가 바뀌면 소환 횟수/통계 자동 초기화
- 첫 구간 30회 → 사용자가 원할 때 마지막 20회 개방 → 최종 50회 종료
- 50회 최종 보고서: 총 소환 / 전설 / 에픽 / 레어 개수
- **오늘의 운명 시험 초기화** 버튼 추가
- 초기화 버튼은 몰입을 방해하지 않도록 진행도 아래에 작고 낮은 강조도로 배치
- 초기화 버튼 클릭 시 전용 확인창 표시:
  - “당신의 운명 시험은 종료되었습니다. 운명을 거스르겠습니까?”
  - `아니오` → 그대로 유지
  - `예, 운명을 거스른다` → 오늘 횟수/희귀도 통계를 0으로 초기화
- 초기화 후 다시 0/30부터 시작
