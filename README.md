# worwiki v2.14.45

## 작업 내용
- 영웅 목록 썸네일 자동 정규화 시스템 추가
- 앞으로 어떤 영웅 이미지를 넣어도 목록 카드에서는 공통 규격으로 자동 맞춤
- 카드 비주얼 영역을 고정 높이/고정 비율로 통일
- 목록 이미지에 자동 contain + 하단 기준 정렬 + 공통 scale 적용
- 로살리아 / 베이라시아 / 오켄바르처럼 큰 원본도 별도 개별 보정 없이 공통 규칙으로 바로 정리

## 핵심 원칙
- 원본 이미지를 바꿔도 목록 카드가 커지거나 밀리지 않도록 구조 자체를 수정
- 이후 신규 영웅/이미지 교체 시 매번 수동 크기 보정하지 않아도 되도록 처리

## 반영 파일
- `_worker.js`
- `VERSION.txt`

## 적용 방법
1. 기존 파일 백업
2. ZIP 압축 해제
3. `_worker.js`, `VERSION.txt` 덮어쓰기 업로드
4. 배포 후 목록 카드 썸네일 크기 확인
