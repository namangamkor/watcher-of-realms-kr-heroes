# v2.14.155 마법병사 상세 +버튼 첫 클릭 오류 수정

- 현재 패치: v2.14.155
- 기준 버전: v2.14.154
- 수정일: 2026-10-19 (Asia/Seoul)
- 배포 상태: 패치 제작 완료 / 실제 사이트 미배포

## 원인과 수정

검색어를 입력한 뒤 카드의 +버튼을 처음 누르면 검색창에서 포커스가 빠지면서
change 이벤트가 추가로 발생했습니다. 이때 카드들을 같은 위치에 다시 붙이는 처리로
진행 중인 클릭이 끊어져, 추천 근거·능력치 및 대표 스킬 등이 첫 클릭에 열리지 않았습니다.

검색은 input 이벤트에서 처리하고, 검색창의 중복 change 이벤트는 제외했습니다.
현재 카드 순서와 표시할 순서가 같으면 카드를 다시 배치하지 않도록 수정했습니다.
추천 근거·능력치 및 대표 스킬·개편 예고의 기본 펼침/접기 동작을 유지합니다.

## 적용

v2.14.154에 ZIP의 10개 파일을 저장소 루트에 함께 덮어씁니다.
_worker.js·app.js·heroes.json 필수 동기화 세트와 README.md·VERSION.txt를 포함합니다.
HTML 및 JS·CSS의 버전 참조는 v2.14.155로 맞췄습니다.
추가 WebP는 없습니다.

이전 한글 검색 수정, 마법병사 53종·추천 12종·개편 예고 7종,
영웅 261명의 데이터와 기존 정렬 순서는 유지했습니다.

## 검증

- 수정 전 검색 직후 첫 + 클릭이 무시되고 두 번째 클릭에서 열리는 오류 재현.
- PC 마우스·모바일 터치에서 추천 근거, 능력치·대표 스킬, 카드 개편 예고, 전체 개편 예고의 첫 클릭 펼침·두 번째 클릭 접힘 검증.
- 위 8가지 첫 클릭 검사에서 주소 해시 변경과 비정상 화면 이동이 없음을 확인.
- 제목 영역 클릭 및 키보드 Enter·Space 조작 검증.
- 한글 검색 수정, 정렬 4종, 추천·등급·생물 특성 필터, 검색 결과 없음, 초기화 검증.
- Worker 응답·정적 HTML·JSON·필수 동기화 세트의 일치와 영웅 데이터 보존 확인.
- 실제 운영 사이트 배포는 수행하지 않았습니다.
