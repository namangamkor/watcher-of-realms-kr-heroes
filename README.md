## 변경

메인 업데이트 내용은 공백 포함 최대 20자로 제한하며, 초과하면 19자와 말줄임표로 표시합니다. 모바일에서도 내용은 한 줄로 유지하고 화면 폭을 넘으면 말줄임 처리합니다. 영웅명과 날짜는 이 글자 제한 대상이 아닙니다.

제누스 업데이트 표시를 “이미지 교체 · 수집가치 3점”으로 축약했습니다. 원문 이력과 상세페이지 평가 사유는 보존합니다. updateHistory에 선택적인 shortMessage를 두어 짧은 표시문을 관리합니다. 지정하지 않으면 message를 자동 축약합니다. Worker와 브라우저에서 동일하게 적용합니다.
