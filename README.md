## 운영 사이트에서 확인한 배포 상태
2026-09-27 확인 기준, 실제 worwiki.kr 운영 사이트는 **v2.14.16~v2.14.16a 계열로 추정**됩니다.

근거:
1. `/growth-guide/` 하단에 `v2.14.16` 표기가 남아 있음.
2. v2.14.17에서 추가된 메인 4개 링크 배너가 운영 사이트에 보이지 않음.
3. v2.14.25에서 적용한 이졸데 각성 용어 `방패벽`, `참격`이 운영 사이트에서는 아직 `Shield Wall`, `Slash`로 표시됨.

따라서 **v2.14.17 이후 패치가 GitHub/운영 배포에 실제 반영됐다고 단정하면 안 됩니다.**
Git 저장소의 실제 마지막 커밋은 GitHub 저장소를 직접 확인해야 확정할 수 있습니다.

## 앞으로의 버전 관리 규칙
모든 패치 ZIP에는 아래 파일을 항상 포함:
- `README.md` : 현재 버전 / 기준 버전 / 변경 사항 / 배포 확인
- `VERSION.txt` : 한 줄짜리 현재 버전
- 기존 적용 안내 파일(APPLY.txt 등)

## 주의
ZIP 파일명에 있는 버전은 '제작된 패치 버전'입니다.
그 버전이 실제 GitHub에 업로드되었거나 Cloudflare Pages에 배포되었다는 뜻은 아닙니다.
