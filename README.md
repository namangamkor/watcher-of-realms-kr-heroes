## 수정 내용

한글 조합 중 영웅 카드를 클릭하면 검색창의 입력 확정으로 화면이 위로 움직여 첫 클릭이 빗나가는 오류를 수정했습니다. 일반 왼쪽 클릭 도중 검색창 포커스를 유지해 기존 상세페이지 링크가 첫 클릭으로 열리도록 했습니다. 보조키 클릭·다른 마우스 버튼은 기존 이벤트를 유지합니다.

## 포함 파일 — 총 6개

- `_worker.js`, `app.js`, `heroes.json`: 사용자 지정 필수 동기화 세트.
- `index.html`: 메인의 최신 app.js 버전 연결.
- `README.md`, `VERSION.txt`: 버전·기준·수정일·변경·적용 상태 기록.

그웬돌린 이미지, 마법병사 HTML·JSON·JS·CSS, 영웅 스킬 CSS 등 이미 작업한 별도 파일은 포함하지 않습니다. 기존 저장소의 해당 파일을 그대로 사용합니다. `_worker.js`에 기존에 내장된 영웅·마법병사 데이터는 유지합니다.

## 적용

기존 v2.14.160 전체 묶음 대신 이 ZIP의 6개 파일만 저장소 루트에 함께 덮어씁니다. 기존의 다른 파일은 삭제하거나 덮어쓰지 않습니다. v2.14.159까지의 파일이 이미 적용되어 있어야 합니다.

이전에 제공한 v2.14.160을 이미 적용했다면 다시 적용할 필요가 없습니다. 실행 코드 4개는 해당 파일과 바이트 단위로 같습니다.
