# v2.14.161 이스트리드 수집가치 상향

- 현재 패치: v2.14.161
- 기준 버전: v2.14.160
- 수정일: 2026-10-22 (Asia/Seoul)
- 상태: 패치 제작·검증 완료 / GitHub 적용 및 실제 사이트 배포 미실행

## 변경 내용

- 이스트리드(Estrid) 수집가치: 3.0 → 4.0.
- 상향 사유: **타이탄 초월·장비지하성 2에서 현역으로 사용 가능.**
- 점수와 사유는 사용자가 확정한 평가를 반영했습니다.
- 메인 카드 점수, 상세페이지 점수·사유, 평가 확인일, 정보 업데이트 기록을 갱신했습니다.
- 최근 업데이트와 메인 초기 목록에 이스트리드 변경을 반영했습니다. 실제 운영에서는 기존 최신 정보·후기 활동 정렬 규칙을 따릅니다.
- Worker 내장 데이터·heroes.json·클라이언트·정적 메인을 함께 동기화했습니다.

## 포함 파일 및 적용

아래 **6개 파일만** v2.14.160이 적용된 저장소 루트에 함께 덮어씁니다.

- `_worker.js`, `app.js`, `heroes.json`: 필수 동기화 세트.
- `index.html`: 정적 메인 및 최신 스크립트 연결.
- `README.md`, `VERSION.txt`: 패치 버전·기준·수정일·적용 상태 기록.

이미지·별도 마법병사 파일·별도 CSS는 포함하지 않습니다. 기존 저장소의 나머지 파일을 그대로 사용합니다. DB 변경이나 환경변수 추가는 없습니다.
