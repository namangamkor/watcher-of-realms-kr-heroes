# 워처 오브 렐름 위키 v2.14.97

- 현재 버전: v2.14.97 / 적용 기준: v2.14.96
- 파일 제작·로컬 검증 완료. 실제 사이트 적용·배포는 미실시.

## 변경

258명 전수조사 결과 253명에 추천 아티팩트를 연결했습니다. 기존 누락 109명 중 104명을 보완했습니다. 전용 아티팩트가 확인되면 전용 우선, 그 외에는 영웅별 범용 추천을 사용합니다. 사용자 제공 공식 한국명 10종을 반영했습니다.

미확정 5명(커터·드레가·바로드라쿠스·베라·사스니)은 추가 근거 또는 장착 확인이 필요하여 기존 상태를 유지했습니다. 후보와 전체 추천 근거는 ARTIFACT_AUDIT.md에 있습니다. 전용 우선은 사이트 추천 정책이며 모든 콘텐츠의 최적 세팅을 의미하지 않습니다.

추천 변경 시 이전 아티팩트의 효과 설명이 새 이름 아래에 표시되지 않도록 이름 일치 검사를 추가했습니다. Worker 데이터·홈 HTML과 데이터 캐시 버전을 동기화했습니다.

## 적용

v2.14.96이 적용된 저장소에 이 ZIP의 heroes.json, _worker.js, index.html, app.js를 같은 경로로 덮어쓰고 기존 방식으로 배포하세요. 기존 파일을 삭제하지 마세요. README.md·VERSION.txt·ARTIFACT_AUDIT.md는 검토 자료입니다. 이전 버전을 사용 중이라면 먼저 v2.14.96까지 적용해야 합니다.

변경 파일만 포함하며 영웅 이미지 파일은 포함하지 않습니다.

## 검증

258명 보존, 추천 한국명·보류 대상 확인, 추천 외 영웅 데이터 보존, Worker 내장 데이터·홈 HTML 일치, JavaScript 문법 및 추천 카드 렌더링을 검사했습니다. 실제 배포 화면은 미검증입니다.
