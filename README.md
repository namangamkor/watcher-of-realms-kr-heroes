## 오류 원인과 수정

v2.14.157에서 그웬돌린에만 추가한 전체 이미지 맞춤 스타일이 공통 카드 폭보다 이미지를 작게 만들었습니다. 이 예외 스타일을 정적 메인과 Worker 내장 메인 양쪽에서 제거했습니다.

그웬돌린도 다른 영웅과 동일한 공통 이미지 크기 규칙을 사용합니다. 상세 보기와 간략 보기, 검색으로 다시 생성한 카드에 동일하게 적용됩니다. 다른 카드의 레이아웃은 변경하지 않았습니다.

- 버전 참조 외 영웅·마법병사 데이터 및 공통 동작 변경 없음.
