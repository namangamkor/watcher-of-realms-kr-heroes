# v2.14.61 · 업데이트 목록에서 오켄바르가 사라지는 문제

기준 버전: v2.14.60 (이전 패치 적용 후 사용)
변경 파일: app.js 한 개

원인: 첫 화면 Worker HTML에는 신규 영웅 업데이트가 있으나, 클라이언트 app.js의 고정된 HERO_DISPLAY_ORDER에는 오켄바르와 베이라시아가 없습니다. /api/recent-updates 응답을 받은 뒤 applyHeroActivity가 이 둘의 활동 데이터를 버려 다시 렌더링하면서 카드가 사라졌습니다.

수정: API가 반환한 영웅 ID를 고정 목록에 없다는 이유로 제외하지 않습니다. 기존 시간순 정렬과 카드 표시는 유지합니다.

배포: 이 ZIP의 app.js를 사이트 루트의 app.js에 덮어쓰고 배포하세요. v2.14.60 배포 후 적용하는 차분 패치입니다. 실제 배포는 아직 하지 않았습니다.
