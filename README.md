# 워처 오브 렐름 위키 v2.14.91

- 현재 패치: v2.14.91
- 마지막 확인된 배포 기준: v2.14.81
- v2.14.82~v2.14.91 배포 여부: 미확인. v2.14.90까지 포함한 누적 패치입니다.

## 주요 변경
- 베이라시아 주 장비를 악의 복수, 보조 액세서리를 영혼의 비밀로 변경했습니다.
- 추천 아티팩트를 흐르는 팬던트로 등록했습니다. 효과 설명은 제공되지 않아 임의로 작성하지 않았습니다.
- 추천 옵션을 공격력 보너스, 치명타율, 치명타 피해, 분노 회복 효율로 변경했습니다.
- 이전 누적 패치의 영웅 목록, 초상화, 추천 옵션 표시 및 용어 수정도 포함합니다.

## 적용과 검증
ZIP 내부 파일을 저장소 최상위에 덮어쓰고 배포하세요. ZIP 자체는 올리지 마세요. Worker 내장 영웅 데이터와 heroes.json의 258명 일치, 베이라시아 값, JavaScript 문법을 검사했습니다. 실제 배포 화면은 미검증이며 삭제할 파일은 없습니다.
