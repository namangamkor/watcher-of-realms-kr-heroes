# 워처 오브 렐름 위키 v2.14.81 — 가드리엘 이미지 교체

기준: 사용자 배포 확인 v2.14.75. v2.14.76~v2.14.80 변경 사항도 이 패키지에 누적 포함했습니다. v2.14.80의 배포 여부는 확인되지 않았으나, 기존 이비 프라이 이미지 삭제는 사용자가 완료했습니다. v2.14.81은 아직 배포되지 않았습니다.

## 적용
ZIP 안의 파일을 저장소 최상위에 같은 이름으로 덮어쓰고 새 WebP 두 개를 업로드한 후 배포하세요. 이 패키지에 없는 파일은 그대로 둡니다.

## 이번 변경
- 가드리엘(Idril)의 감시자/별을 꿰뚫는 자 양쪽 진영 이미지가 모두 `idril-dual-faction-v21481.webp`를 사용합니다. 상세 페이지도 같은 데이터의 이미지를 사용합니다.
- `heroes.json`, `_worker.js`, `index.html`을 동기화하고 `app.js` 캐시 버전도 2.14.81로 갱신했습니다.

## 배포 후 삭제 후보

- `star-piercers-hq-35-idril.webp`
