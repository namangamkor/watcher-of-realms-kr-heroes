# v2.14.142 장비 프리셋 이용 안내 보강

- 작업일: 2026-10-16 Asia/Seoul
- 기준 버전: v2.14.141
- 상태: 패치 제작 완료 / 미배포

## 변경사항
승인 v3 선택 카드 아래에 다음 콘텐츠를 추가했습니다.
1. 성장용 V4.0과 END V1.0 선택 기준 및 상세페이지 링크
2. 공유 코드 적용 방법: 기존 END 상세페이지에 기재된 '추천 설정 → 프리셋 정리 → 프리셋 가져오기' 경로 사용
3. 기존 프리셋 보관 및 가져오기 시 덮어쓰기 주의사항
4. FAQ 4개: 설정 선택, END 추천 빈도, 게임 추천과 END 조건의 차이, 코드 위치
200판에서 2개를 얻은 기록은 해당 실험 결과이며 일반 확률이 아님을 명시했습니다. 코드는 상세페이지에서 계속 관리합니다.
v2.14.141의 검색 제목·설명·대제목을 유지하고 화면 버전을 v2.14.142로 갱신했습니다.

## 보존 및 참조
gear-presets.html과 _worker.js의 WW_PRESET_HUB_HTML을 동기화했습니다. 기존 카드 HTML·CSS, 이미지, 버튼 링크, 업데이트 날짜 및 주의사항은 유지했습니다. app.js와 heroes.json은 기준 버전 그대로 한 세트로 동봉했습니다. 그 외 Worker 코드는 동일합니다. FAQ는 기본 HTML details/summary로 동작하며 추가 JS나 애니메이션이 없습니다.

## 적용
ZIP의 8개 파일을 저장소 루트에 같은 이름으로 덮어씁니다. 기존 나머지 파일은 유지하세요. 전체 백업이 아닌 패치입니다. v2.14.141이 적용되지 않았어도 v2.14.140 기준 선택 화면에 본 검색 정보와 안내를 함께 반영할 수 있습니다.

## 검증 및 배포 상태
JavaScript 구문 검사, 정적/내장 HTML 동일성, 기존 카드 보존, app.js·heroes.json·이미지 동일성, FAQ 4개 확인을 통과했습니다.
PC·모바일 브라우저 시각 검증은 환경 제약으로 미완료입니다. 안내 비교는 PC 2열·모바일 1열로 작성했습니다. 배포 후 좁은 모바일 폭에서 안내 및 FAQ 줄바꿈, 코드 페이지 이동을 확인하세요.
Search Console에서 이미 색인 요청을 했다면 같은 URL을 반복 요청할 필요는 없습니다. 이 패치는 자동 배포·색인 요청·검색 순위 보장을 수행하지 않습니다.
