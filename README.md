# Watcher of Realms KR Heroes


- 폰 앱 아이콘을 `W 메인 + 나만겜 배지` 조합으로 개선
- 기존 `구독!` 이모티콘은 사이트 배너용으로 유지
- PWA 아이콘 3종 교체:
  - `icon-192.png`
  - `icon-512.png`
  - `icon-maskable-512.png`

워처 오브 렐름 한국명 ↔ 영문명 매칭용 영웅도감.

## v1.1 — 브랜드/메인 카피 정리

- 카카오톡 등 앱 내 브라우저 자동 감지 및 Chrome 안내

- 이름 검색 시작 시 희귀도 / 직업 필터 자동 `전체` 초기화
- 검색 후 다시 필터 선택 가능
- `폰에 도감 추가` 버튼
- Android/Chrome 설치 프롬프트 지원
- iPhone/iPad Safari `홈 화면에 추가` 안내
- 홈 화면 앱 아이콘 추가
- standalone 앱 모드
- Service Worker 캐싱
- 기본 오프라인 대응
- 나만겜 제작·운영 브랜딩 유지
- 파수꾼 소대 (Watch Guard) 40명
- 한국명 / 영문명 실시간 검색
- 희귀도 / 직업 필터

## v2.7.0 변경 — 영웅 상세 URL / SEO 상세페이지

- 기존 검색/필터 영웅도감 디자인과 동작은 유지

- 영웅별 title 형식: `초선(DiaoChan) - 워처 오브 렐름 영웅도감 | 나만겜`

- `sitemap.xml`을 메인 1개 + 영웅 253개 = 총 254개 URL로 확장
- 잘못된 영웅 URL은 404 + noindex 처리

- 캐시 버전 `v2.7.0`

### 배포 참고
`_worker.js`는 Cloudflare Pages Advanced Mode를 사용합니다. 영웅 상세 URL 외 요청은 `env.ASSETS.fetch()`로 기존 정적 사이트를 그대로 전달하므로 메인 도감은 기존 방식 그대로 동작합니다.
