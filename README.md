## 표시 방식

- 목록의 검색 영역 위에 접어서 보는 길드전 개편 예고를 배치했습니다.
- Mortal Curse 지속시간 15초→영구, 중첩당 10%와 최대 8중첩 유지, 소환수 배치 규칙을 함께 안내합니다.
- 개편 대상 7종의 이름을 누르면 해당 카드의 변경 전후가 펼쳐집니다.
- 카드에 개편 예고 배지를 표시하고 변경 전후·유지 항목·재검토 포인트를 구분합니다.
- 슬로터의 기존 조합 추천과 추가 예고를 함께 표시합니다.
- 추천 근거와 패치 예고를 구분하며 예고만으로 신규 티어나 추천 등급을 부여하지 않았습니다.
