# 나만겜 위키 v2.14.186 — 연구소 배너 표시 수정

기준 버전 v2.14.185.

배너를 WebP로 압축하고 Worker에서 이미지 주소에 직접 응답하도록 수정했습니다.
외부 정적 파일 배치와 관계없이 연구소 이미지가 표시됩니다. 배너 주소는 기존 HTML과 호환됩니다.

적용 · 저장소 루트의 _worker.js를 교체하고 재배포합니다.
README.md와 VERSION.txt를 버전 기록으로 함께 반영합니다.
연구소·계산기와 포레스·타롤라 소환 이력이 포함된 최신 Worker입니다.

검수 · 이미지 MIME, 실제 WebP 바이트, 연구소 배너 연결, HEAD 응답 및 기존 페이지 경로를 확인했습니다.
배포 상태 · 패치 작성, 사이트 미배포.
