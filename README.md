## 목적

END 장비 기준에서 폐기하기로 확정한 `불굴의 용사`, `신성한 영혼`, `원시의 분노`가 영웅별 최종 추천 장비에 남아 있는지 v2.14.122 기준으로 전수 확인했습니다.

현재 영웅 데이터에서 실제 수정이 필요한 영웅은 2명입니다.

1. 렉스
   - 기존: 불굴의 용사 + 강철 의지
   - 변경: **성흔의 수호 + 강철 의지**
   - 이유: 불굴의 용사는 END 제외. 동일 생존 역할의 상위 세트인 성흔의 수호로 교정.

2. 로크
   - 기존: 불굴의 용사 + 재앙 드래곤
   - 변경: **성흔의 수호 + 재앙 드래곤**
   - 이유: HP 기반 딜러 구조와 재앙 드래곤은 유지하고, 왼쪽 2세트만 상위 세트로 교정.

`신성한 영혼`과 `원시의 분노`는 v2.14.122의 `heroes.json` 및 Worker 내 영웅 데이터에 추천 장비로 존재하지 않아 이번 영웅 데이터 패치에서 수정 대상이 없었습니다. 장비 프리셋 정적 페이지의 제거 작업은 별도 단계입니다.

## 변경 파일

- `heroes.json` — 렉스·로크 추천 장비 수정
- `_worker.js` — 내장 HEROES 데이터의 렉스·로크를 `heroes.json`과 동일하게 동기화
- `README.md`
- `VERSION.txt`

`app.js`는 v2.14.122 원본을 함께 검수했으며 폐기 장비 추천 데이터가 없어 수정하지 않았습니다.
