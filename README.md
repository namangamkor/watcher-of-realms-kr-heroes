# v2.14.152 마법병사 도감 타이틀 이미지 교체

- 현재 패치: v2.14.152
- 기준 버전: v2.14.151 (v2.14.150에서도 바로 적용 가능)
- 수정일: 2026-10-19 (Asia/Seoul)
- 실제 사이트 적용: 미확인

## 변경 사항

사용자가 승인한 마법병사 5종의 단체 이미지로 도감 제목 옆 대표 이미지를 교체했습니다.
슬로터, 마리아스 여백작, 사막 타이탄, 열등한 악마, 서리 폭발충이 포함된 새 이미지입니다.
승인한 PNG를 무손실 WebP로 변환했으며 1536×1024 비율·색상·투명도를 그대로 유지했습니다.
이미지를 자르지 않는 기존 배치와 투명 배경을 사용하고, 대체텍스트·공유 미리보기 이미지도 맞췄습니다.
작은 화면에서 도입 이미지를 숨기는 기존 반응형 규칙은 유지됩니다.

## 적용

ZIP의 11개 파일을 저장소 루트에 함께 덮어씁니다.
필수 동기화 세트 _worker.js·app.js·heroes.json과 메인 HTML, 마법병사 HTML·JSON·JS·CSS, README·VERSION을 포함합니다.
신규 WebP는 타이틀 이미지 1개입니다. 기존 병사 이미지 묶음은 포함하지 않았습니다.
이전 대표 이미지 demon-soldiers-cover-v214151.webp는 이 패치부터 참조하지 않으므로 삭제해도 됩니다.

마법병사 53종·추천 11종·개편 예고 7종·영웅 261명과 도감 카드 이미지는 유지했습니다.
Worker 내장본과 HTML·JSON·JS 버전, 신규 이미지 경로 및 무손실 변환을 검사했습니다.
브라우저 시각 검수와 실제 배포는 수행하지 않았습니다.
