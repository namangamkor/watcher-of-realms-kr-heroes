# 워처 오브 렐름 위키 v2.14.98

현재 패치 v2.14.98 / 기준 v2.14.97. 제작·로컬 검증 완료, 실제 적용·배포 미실시.

## 변경

영웅 상세의 추천 아티팩트 아래 소환 이력 추가. 마지막 등장, 다음 예정, 시작된 행사 수, 전체 및 소환 종류별 등장 간격 표시. 1회 기록은 계산하지 않고, 2회는 간격 1건, 3회 이상은 평균·최단·최장 표시. 한국 날짜로 자동 전환하며 예정은 평균에서 제외. 시작일 기준 계산, 같은 시작일 중복 간격 제외. 이력이 있는 영웅만 섹션 표시.

사용자 제공 2026년 10월 4개 행사, 7명 기록. 손오공은 200회 확정 소환, 나머지는 종류 미확인으로 기록했으며 일반·고대를 임의로 지정하지 않았습니다. 출처는 사용자 제공 일정이며 공식 공지 링크를 확인했다고 표기하지 않았습니다.

현재 기준 데이터에 있는 베아트릭스·해골그림자회색수염·손오공·로살리아·세르게이 5명에 summonHistory 연결. 가로크·아멜리아 에인스워스는 기준 데이터에 없어 summon-events.json과 Worker 일정 목록에 보존했습니다. 향후 같은 한국명 또는 해당 이름을 aliases에 가진 영웅이 등록되면 자동 표시합니다. 새 영웅의 능력·진영·이미지는 임의로 생성하지 않았습니다.

## 적용

v2.14.97까지 적용한 저장소에 heroes.json, _worker.js, app.js, index.html, summon-events.json을 같은 경로로 덮어쓰고 기존 방식으로 배포하세요. 기존 파일을 삭제하지 마세요. 최근 별도 변경한 저장소라면 전체 파일 덮어쓰기 전에 병합이 필요합니다. 이미지 파일은 포함하지 않습니다.

## 다음 일정 추가 방법

heroes.json의 해당 영웅 summonHistory에 id, startDate, endDate, type, guaranteePulls, companions, source, recordedAt을 기록합니다. 날짜는 YYYY-MM-DD. type은 regular(일반), ancient(고대), guaranteed(확정), unclassified(미확인). 반복 행사에는 새 고유 id를 부여합니다.

Worker의 HEROES 내 같은 영웅 데이터도 반드시 동기화하세요. summon-events.json은 행사 전체 원장입니다. 원장과 Worker의 SUMMON_EVENTS에도 같은 행사 정보를 반영합니다. 원장을 저장하는 것만으로 Worker가 자동 갱신되지는 않습니다. id가 같으면 중복 표시하지 않습니다. 신영웅 등록 후 원장의 id:null을 실제 영웅 id로 교체하세요.
