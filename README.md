1. ZIP 압축을 풉니다.
2. 아래 6개 파일을 현재 GitHub 저장소 **루트에 같은 파일명으로 덮어 올립니다**.
3. 기존 GitHub/Cloudflare 배포 절차로 반영합니다.

| 파일 | 내용 |
| --- | --- |
| `_worker.js` | 오켄바르 장비 영문명 교정, 홈/상세 버전 갱신 |
