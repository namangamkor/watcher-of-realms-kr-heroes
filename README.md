# v2.14.159 그웬돌린 스킬·각성 갱신 및 관련 영상 삭제

- 현재 패치: v2.14.159

- 제작·검증 완료 / GitHub 업로드 및 실제 사이트 배포 미실행

## 변경 내용

사용자가 제공한 한국 서버 게임 화면 9장을 기준으로 그웬돌린 정보를 갱신했습니다.

- 스킬·재능 5개 표시: 재능, 단일 실드, 얼음 방패, 희망의 실드, 냉혹한 소동.
- 화면의 기본 수치와 Lv.2~Lv.5 강화분을 구분해 등록했습니다. 최종 실드량·회복량이나 화면에 없는 효과 지속 시간을 임의로 계산해 확정하지 않았습니다.
- 상세 소개를 단일 일반 공격 실드, 범위 궁극기 실드, 실드 종료 시 HP·분노 회복과 물리 취약·빙결 효과에 맞춰 수정했습니다.
- 각성 A1~A5를 한국 서버 화면의 한국어 명칭과 수치로 정정했습니다.
- 그웬돌린의 기존 관련 영상 1개를 삭제했습니다. 상세페이지에서 관련 영상 섹션·카드·썸네일도 표시되지 않습니다.
- 정보 확인일·업데이트 기록·최근 업데이트를 갱신했습니다.
- `_worker.js` 내장 영웅 데이터와 `heroes.json`을 일치시키고, `app.js` 캐시 참조 및 정적 메인도 함께 갱신했습니다.
- 기존 스킬 표시 컴포넌트를 사용하며 해당 스타일 파일도 패치에 포함했습니다.

## 각성 A1~A5

| 각성 | 반영 내용 |
| --- | --- |
| A1 | 냉혹한 소동 적 대상 수 +2명, 물리 취약 효과 20%까지 상승 |
| A2 | HP +1200 |
| A3 | 치사 피해 시 5초 불멸. 해당 기간 일반 공격 범위 내 모든 아군이 1초마다 최대 HP의 10% 회복. 전투마다 최대 1회 |
| A4 | HP +1200 |
| A5 | 얼음 방패 시전 후 자신의 최대 HP 10% 증가, 전투 동안 영구 지속, 최대 3회 중첩 |

기존의 A1 추가 1명 피해, A3 궁극기 주변 보호막, A5 최대 HP 8% 설명을 이번 화면 기준으로 교체했습니다. 각성의 해외 DB 번역 안내도 한국 서버 화면 확인 안내로 갱신했습니다.
