## 수정 내용

v2.14.117의 아멜리아 상세페이지에 추천 데이터가 없어 장비·아티팩트 배너가 표시되지 않았고, 기존 템플릿에 없던 스킬 정보와 추격 연계 효과 섹션이 추가되어 있었습니다. 이 패치에서 해당 두 섹션과 추가 스타일시트 참조를 제거하고 **기존 상세페이지 템플릿으로 복구**했습니다.

공통 상세페이지의 HTML·CSS와 표시 순서를 유지합니다. 소개 다음에 **추천 장비 → 각성 A1~A5 → 추천 아티팩트**가 기존 배너 형식으로 표시됩니다. 장비·아티팩트·각성 렌더러는 v2.14.116의 기존 코드와 동일합니다.

| 항목 | 아멜리아에 반영한 내용 |
| --- | --- |
| 추천 장비 | 전쟁의 주인 (Warlord) 세트 + 영혼의 비밀 (Soulbound Arcana) 세트 |
| 추천 옵션 | 공격력 보너스, 치명타율, 치명타 피해, 분노 회복, 공격 속도 |
| 추천 아티팩트 | 망령술사의 손가락 (Blightcaller's Claw), 범용 추천 |
| 각성 | 사용자 제공 스크린샷의 A1~A5 유지 |

장비와 아티팩트는 기존 위키에서 확인된 한국 공식명과 아이콘을 사용합니다. 장비는 제공된 스킬 구조와 해외 후보를 바탕으로 조합한 **범용 추천**이며, 확정된 최종 장비 순위로 표시하지 않습니다. 추천 옵션도 기존 옵션 배너를 사용합니다.

아멜리아, 황혼 그림자의 칼날 진영, 259명 집계, 최근 활동순 정렬, 새 초상화는 유지합니다. 초상화는 사용자가 제공한 600×800 WebP 원본과 바이트가 동일합니다. 수집가치는 평가 준비 중으로 유지합니다. 기존 258명의 영웅 데이터와 상세페이지 구성, 오켄바르의 `강철 의지 = Tempered Will` 교정을 유지합니다. 가로크는 이번 패치에 등록하지 않았습니다.

## 포함 파일 및 적용 방법 — 총 8개

ZIP을 풀고 아래 8개 파일을 현재 저장소 **루트에 같은 파일명으로 덮어씁니다**. 기존 GitHub/Cloudflare 배포 절차로 적용합니다. v2.14.117 위에 적용할 수 있으며, v2.14.116에서 바로 적용해도 아멜리아 등록 변경이 함께 반영됩니다. 전체 저장소를 대체하는 백업 파일은 아닙니다.

| 파일 | 내용 |
| --- | --- |
| `_worker.js` | 기존 상세 구성 복구, 추천 배너, 내장 영웅·홈 데이터 동기화 |
| `heroes.json` | 아멜리아 추천 정보, 소개·각성·신규 진영·등록 이력 |
| `app.js` | 신규 진영·기존 정렬 유지, 데이터 캐시 버전 갱신 |
| `index.html` | 259명 집계·신규 진영·홈 업데이트·캐시 버전 |
| `grey-blades-hq-01-amelia-ainsworth-v214117.webp` | 사용자 제공 초상화 원본 유지 |
| `sitemap.xml` | 아멜리아 상세 URL 포함 |
| `README.md` | 버전·변경사항·적용 방법·검증·배포 상태 |
| `VERSION.txt` | 버전 추적 정보 |

v2.14.117에서 추가했던 `hero-skills.css`는 이 패치에서 참조하지 않습니다. 저장소에 해당 파일이 남아 있어도 페이지에 로드되지 않으므로 삭제 작업은 필요하지 않습니다.
