# v2.14.162 번개 수비병 추천 추가

- 패치 버전: v2.14.162
- 기준 버전: v2.14.161
- 수정일: 2026-10-22 (Asia/Seoul)
- 상태: 제작·검증 완료 / GitHub 적용 및 실제 사이트 배포 미실행

## 변경 내용

- 기존 도감의 번개 수비병(Lightning Guard)을 추천에 추가했습니다.
- 기존 레전더리·비행 분류와 이름·이미지·능력치·스킬은 유지했습니다.
- 기존 추천 10종을 유지하여 총 추천은 11종입니다.
- 추천 배지·추천 이유·근거 영역, 추천만 보기 집계, 추천 기준과 날짜를 갱신했습니다.
- 추천 근거는 사용자의 2026-10-22 추가 지시와 기존 도감의 게임 화면 기반 역할 설명입니다. 공중에서 번개 공격으로 주변 적에게 범위 마법 피해를 입히는 역할을 반영했습니다.
- 전체 53종과 기존 분류·검색·정렬 기능을 유지했습니다.
- Worker 내장 HTML·데이터, 정적 마법병사 페이지, JSON, 화면 내장 검색 데이터를 일치시켰습니다.

## 최종 추천 11종

슬로터, 마리아스 여백작, 그레시우스, 사막 타이탄, 북키퍼, 열등한 악마, 자이언트 골렘, 우매한 자, 워록, 구울견, 번개 수비병.

고급 심연의 눈·망치 수비병·블러드스웜의 추천 제외는 유지합니다. 각 병사의 기존 근거와 확인일은 보존했으며, 이번 추가 병사와 추천 목록 전체의 갱신일만 2026-10-22로 표시했습니다.

## 포함 및 적용 — 총 7개

v2.14.161이 적용된 저장소 루트에 아래 7개 파일을 함께 덮어씁니다.

- `_worker.js`, `app.js`, `heroes.json`: 필수 동기화 세트. app.js와 heroes.json은 v2.14.161의 검증된 파일 그대로 동봉했습니다.
- `demon-soldiers.html`, `demon-soldiers.json`: 이번 추천 변경 파일.
- `README.md`, `VERSION.txt`: 버전·기준·수정일·적용 상태 기록.

메인 HTML·이미지·CSS·마법병사 JS는 이번 묶음에 포함하지 않습니다. 기존 파일을 사용합니다. 기존 마법병사 JS·CSS 참조 버전도 유지합니다. 추천 추가는 데이터와 HTML만으로 반영되며, 기존 클라이언트의 추천 필터가 새 항목을 인식하는 것을 확인했습니다. DB 변경·환경변수 추가는 없습니다.

- 기존 10종 유지 + 번개 수비병 추가 = 추천 11종 확인.
