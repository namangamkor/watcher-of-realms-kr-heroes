## 수정

제누스 사진·평가 변경을 최신 업데이트에 등록하고 카드 최신순에 반영. 기존 정렬은 별도 편집 기록과 공개 후기의 최신 시간 기준이었으며, 제누스 수정 기록 누락으로 정렬되지 않았습니다.

영웅 데이터의 infoUpdatedAt(시간대 포함 ISO 날짜)과 updateHistory(변경 이력)를 상단 목록·정렬의 공통 입력으로 연결했습니다. updateHistory 항목: id(고유), updatedAt(시간대 포함 ISO), kind, kindLabel, message. 영웅이 수정되면 이 두 필드를 함께 기록하고 Worker HEROES도 동기화합니다. 기존 편집 기록과 공개 후기는 유지합니다.

정렬 기준: 정보 수정일과 최신 공개 후기 중 더 최근인 시간 내림차순. 동률이면 후기 순서, 기존 순서. API 실패 시 heroes.json 수정일로 정렬. 초기 HTML과 Worker 홈에도 제누스 최신 업데이트·이미지·첫 카드 반영. 기존 필터·더 보기에서도 같은 정렬 사용. 더 최근 공개 후기가 있으면 그 영웅이 제누스보다 앞에 표시됩니다.

상단 최근 3건을 서버에서도 표시하고 브라우저에서 최신 후기와 함께 갱신. 전체 영웅 일괄 아티팩트 검수 등 과거 작업의 정확한 영웅별 수정 시각은 새로 추정해 입력하지 않았습니다.
