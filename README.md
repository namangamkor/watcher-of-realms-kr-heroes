# v2.14.151 마법병사 도감 대표 이미지 교체

- 현재 패치: v2.14.151
- 기준 버전: v2.14.150
- 수정일: 2026-10-19 (Asia/Seoul)
- 실제 사이트 적용: 미확인

## 변경 사항

마법병사 도감 제목 옆 슬로터 이미지를 사용자가 제공한 두 번째 그림으로 교체했습니다.
원본 WebP 958×486 픽셀과 투명 영역을 그대로 유지하고 가로 비율에 맞춰 배치했습니다.
기존 슬로터 이름표는 제거하고 대표 이미지 대체텍스트와 공유 미리보기도 함께 맞췄습니다.
도감 내 슬로터 카드의 이미지와 모든 병사 데이터는 유지했습니다.

## 적용

ZIP의 11개 파일을 저장소 루트에 함께 덮어씁니다.
필수 동기화 세트 _worker.js·app.js·heroes.json, 메인 HTML, 마법병사 HTML·JSON·JS·CSS, README·VERSION을 포함합니다.
신규 WebP는 대표 이미지 1개이며 기존 병사 WebP는 포함하지 않았습니다.

마법병사 53종·추천 11종·개편 예고 7종·영웅 261명을 보존하고 관련 버전을 일치시켰습니다.
브라우저 시각 검수와 실제 배포는 수행하지 않았습니다.
