## 변경 내용

- 추천 제외: 고급 심연의 눈, 망치 수비병, 블러드스웜.
- 추천 추가: 워록. 기존 한국명과 영문명 Shadowcaster를 유지합니다.
- 기존 추천 중 나머지 9종 유지. 슬로터 포함.
- 추천 수·배지·추천만 보기·검색용 내장 데이터·추천 기준 설명을 10종으로 동기화했습니다.
- 추천 설명 안의 제외 병사로 향하는 추천 연결도 정리했습니다.
- 워록의 추천 이유는 사용자 확정 목록과 기존 한국 서버 게임 화면의 역할 설명에 근거합니다. 해외 티어 검증으로 표기하지 않았습니다.
