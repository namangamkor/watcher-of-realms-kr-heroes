# v2.14.149 마법병사 추천 표시

- 현재 패치: v2.14.149
- 기준 버전: v2.14.148
- 수정일: 2026-10-19 (Asia/Seoul)
- 제작 상태: 완료
- 실제 사이트 적용: 미확인

## 주요 변경

기획·UI/UX·개발 교차 검토 후 기존 도감에 추천을 통합했습니다.
목록 결과 수 옆에 추천만 보기 버튼을 두고, 추천 11종의 이미지 오른쪽 위에 분류 배지를 표시합니다.
카드에는 추천 이유와 사용 조건을 바로 보여주며, 추천 근거·출처를 펼치면 의견 날짜·원문·평가 범위를 확인할 수 있습니다.
별도의 추천 카드 목록을 복제하지 않아 같은 병사를 두 번 스크롤하지 않습니다.

| 분류 | 병사 |
| --- | --- |
| 육성 추천 | 열등한 악마, 구울견 |
| 장군 추천 | 마리아스 여백작, 그레시우스, 사막 타이탄 |
| 조합 추천 | 블러드스웜, 고급 심연의 눈, 우매한 자, 슬로터 |
| 조건부 추천 | 자이언트 골렘, 망치 수비병 |

추천은 2026년 해외 커뮤니티의 길드전 공격 실전 의견을 정리한 편집 추천입니다.
능력치의 S~SSS 등급과는 별도로 표시합니다. 요구 레벨·연계 전투력·상대 방어 편성에 따라 적합성이 달라집니다.
구울견은 원문의 에픽 개들 표현을 해당 종에 연결한 해석임을 근거에 밝혔습니다.
추천 판단일과 자료 게시일·의견 날짜를 구분하고 2026-10-16 밸런스 조정 예고를 연결했습니다.

## 데이터 동기화

추천 내용과 출처는 demon-soldiers.json에서 관리합니다.
같은 자료로 카드 HTML·검색 데이터·Worker 내장 HTML·Worker JSON을 생성했습니다.
모든 관련 JS와 HTML의 버전을 맞추고 CSS URL에도 새 버전을 적용했습니다.
기존 마법병사 페이지의 제외 요청된 해외 사이트 영문명 링크를 제거했으며 확정된 이름은 유지했습니다.
영웅 261명, 마법병사 53종(장군 6·레전더리 20·에픽 27), 이미지 경로, 능력치와 대표 스킬을 유지합니다.
이전에 삭제한 영문명 안내 문단도 다시 추가하지 않았습니다.
