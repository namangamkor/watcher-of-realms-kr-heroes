운영 원칙
- 성장 단계가 아닌 최종/엔드게임 장비만 메인 추천
- 한국 서버 공식명 + 영어 원명 병기
- 한국 서버 명칭은 사용자 제공 게임 내 스크린샷 우선
- 영웅별 해외 최신/현재 빌드를 개별 확인
- Fastidious.gg와 Prospector.gg를 중심으로 교차검증
- 콘텐츠 차이가 실제로 큰 경우에만 설명에 짧게 언급

주요 개별 판정
- 에드린: 성흔의 수호 + 재앙 드래곤 (HP 기반 DPS)
- 브로켈/이졸데/카드그림/킹 할츠/크로돌/말비라/오라그/로크스: 성흔의 수호 + 강철 의지
- 에블린/다그나/드레린: 성흔의 수호 + 불멸의 의지
- 에일리스/그웬돌린/미덴/사티/와엘: 빛의 은혜 + 성스러운 날개
- 에르드/하르벤/젤라/루루/녹턴/워로스: 악의 복수 + 마수의 포효
- 페르샤/샤미르/소설백: 악의 복수 + 지옥 비명
- 나머지 주요 딜러 다수: 악의 복수 + 재앙 드래곤
- 바크라: 악의 복수 + 재앙 드래곤을 대표 추천, 마수의 포효는 상황별 대안으로 설명
- 마리엘: 전쟁의 주인 + 성스러운 날개, 딜보다 공격 속도/분노 회복 우선
- 레이븐홀드: 전쟁의 주인 + 성스러운 날개
