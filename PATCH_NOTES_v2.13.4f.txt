WoR Wiki v2.13.4f - 닉네임 검수/익명 승인 패치

1. 작성 단계 닉네임 금칙어 검사
- 욕설·성적 표현·운영자 사칭 닉네임을 입력하면 즉시 "닉네임을 변경해주세요." 안내
- 댓글 본문/각성 입력값은 지우지 않음
- 클라이언트 검사 + Worker 서버 검사 이중 적용
- 공백/일부 특수문자로 금칙어를 우회하는 형태도 검사
- 예: "작은곧휴몽글", "작은곧 휴몽글" 차단
- 일반 표현 예: "작은곰몽글", "고추장인"은 현재 차단하지 않음

2. 관리자 익명 승인 기능
- 승인 대기/숨김 후기: "익명 처리 후 승인" 버튼 추가
  -> 닉네임을 "익명"으로 바꾸고 즉시 공개 승인
- 이미 공개된 후기: "닉네임 익명 처리" 버튼 추가
  -> 후기 내용/각성/등록일은 그대로 두고 닉네임만 "익명"으로 변경
- 별도 D1 마이그레이션 불필요
