v2.14.16a 성장 가이드 화면 복구 패치

v2.14.16 적용 후 성장 가이드의 스타일과 이미지가 나오지 않을 때 적용합니다.

1. ZIP 압축을 풉니다.
2. 압축 안의 파일을 모두 기존 _worker.js와 index.html이 있는 위키 최상위 폴더에 올려 덮어씁니다.
   폴더 안쪽으로 넣지 말고, 파일들을 최상위에 올려주세요.
3. 기존 GitHub → Cloudflare Pages 방식으로 배포합니다.
4. 배포 완료 후 https://worwiki.kr/growth-guide/ 를 Ctrl+Shift+R로 새로고침합니다.

이번 ZIP은 전부 최상위 파일입니다. 하위 폴더를 옮길 필요가 없습니다.
스타일과 스크롤 코드를 HTML에 포함했고, 이미지 5개는 growth-guide-v21416a-로 시작하는 최상위 파일로 제공합니다.
기존 growth-guide 폴더는 삭제하지 않아도 됩니다.
처음이라면 / 성장 순서 구성, 기존 후기 기능과 영웅 데이터는 그대로 유지합니다.
환경변수와 D1 설정 변경은 필요 없습니다.
실제 운영 사이트에 자동 배포하지 않았습니다.
