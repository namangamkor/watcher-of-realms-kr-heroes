newbie/index.html은 newbie 폴더에 넣어야 합니다. 루트 index.html과 혼동하지 마세요.
기존 Cloudflare 자동배포를 사용하며, 설정이나 DB 변경은 없습니다.

변경 사항
- 뉴비 페이지 ‘한 줄로 먼저’ 박스 바로 아래에 관련 나만겜 영상 카드를 추가했습니다.
- 영웅 상세페이지의 기존 영상 카드 생성 함수와 CSS를 그대로 사용합니다.
- YouTube 썸네일, 재생 표시, ‘나만겜 초보자 영상 가이드’ 제목, YouTube 이동 문구를 표시합니다.
- 영상 주소: https://youtu.be/Doe7uvPesXg
- 기존 상단 영상 버튼도 유지했습니다.
- 기존 CSS에 따라 PC는 이미지와 설명을 좌우로, 모바일은 위아래로 표시합니다.
- 썸네일은 다른 영웅 페이지와 동일하게 YouTube 이미지 서버에서 직접 불러옵니다.
- Worker와 정적 newbie/index.html을 함께 갱신했습니다.

검증
Worker 구문, 실제 뉴비 HTML 응답, 썸네일 URL, 링크, 제목, DOM 배치와 정적 HTML 동기화를 확인했습니다.
뉴비 렌더링 함수 외의 Worker 코드는 v2.14.13과 동일합니다.
메인 및 대표 영웅 상세 응답도 이전 버전과 동일합니다.
이 환경에서는 YouTube 이미지 서버 요청이 시간 초과되어 썸네일 실제 로딩은 확인하지 못했습니다.
실제 브라우저 화면 검증 및 운영 배포는 수행하지 않았습니다.

배포 후 /newbie/에서 썸네일 카드와 영상 연결을 확인하세요.
이전 페이지가 보이면 Ctrl+Shift+R로 강력 새로고침하세요.
