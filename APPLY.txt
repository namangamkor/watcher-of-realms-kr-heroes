[기준]
- v2.14.28 소환 확률 적용 버전 기준

[적용]
1. Git 저장소 루트의 기존 _worker.js를 백업합니다.
2. 이 ZIP의 _worker.js, README.md, VERSION.txt 등을 Git 저장소의 같은 루트 폴더에 올립니다.
3. 배포 후 https://worwiki.kr/summon/ 에 접속합니다.
4. `1명 소환`과 `10명 소환` 버튼을 각각 확인합니다.

[1명 소환]
- 기존과 동일한 확률표로 1명 추첨
- 약 2.25초 소환 연출 + 짧은 소환음
- 영웅 이미지/한국명/영문명/희귀도 표시
- 영웅 상세정보 이동 가능

[10명 소환]
- 동일 확률표로 10번 독립 추첨
- PC 결과 화면: 위 5명 + 아래 5명 (5 x 2)
- 태블릿: 3열
- 모바일: 2열
- 각 영웅 카드 클릭 시 기존 영웅 상세페이지로 이동
- 독립 추첨이므로 동일 영웅이 중복 등장할 수 있음

[소환음]
- 별도 MP3/WAV 파일 없음
- 브라우저 Web Audio API로 약 2.3초 길이의 짧은 상승형 소환 테마음을 생성
- 사용자 버튼 클릭을 시작점으로 하므로 일반적인 브라우저 자동재생 제한을 피하도록 구성
- Web Audio 미지원 환경에서는 소리만 생략되고 소환은 계속 동작
- 추후 사용자가 MP3/WAV를 제공하면 이 부분만 실제 음원 재생 방식으로 교체 가능

[확률]
- v2.14.28에서 적용한 확률 규칙 그대로 유지
- crypto.getRandomValues() 유지
- 합계 100% 검증 유지

[저장 기능]
없음: 로그인 / DB / LocalStorage / 소환 이력 / 천장 / 보유 기록
