나만겜 워처오브렐름 위키
v2.14.28 소환 미니게임 확률 적용 패치

[적용]
1. 현재 배포본이 v2.14.27 소환 미니게임 패치 기반인지 확인합니다.
2. Cloudflare Pages 프로젝트의 _worker.js를 이 ZIP의 _worker.js로 교체합니다.
3. 배포 후 https://worwiki.kr/summon/ 을 확인합니다.

[이번 변경]
- 사용자가 제공한 게임 내 소환 확률표를 실제 미니게임 확률에 적용했습니다.
- 표에 적힌 퍼센트는 각 그룹의 '총 확률'이며, 그룹 안의 현재 위키 등록 영웅이 균등 분담합니다.
- 전설 특별 그룹 A: 0.8%
- 전설 특별 그룹 B: 1.0%
- 위 두 표에 없는 나머지 전설: 0.5%
- 에픽 영주/특별 그룹: 6.0%
- 에픽 특별 그룹: 5.0%
- 위 두 표에 없는 나머지 에픽: 10.0%
- 레어: 위 확률을 제외한 나머지 76.7%
- 일반: 0%

[현재 위키 256명 기준]
- 전설 172명 / 에픽 69명 / 레어 13명 / 일반 2명
- 0.8% 전설 그룹: 16명 -> 1명당 0.05%
- 1.0% 전설 그룹: 28명 -> 1명당 약 0.0357142857%
- 나머지 전설: 128명 -> 1명당 0.00390625%
- 6.0% 에픽 그룹: 현재 등록 13명 -> 1명당 약 0.4615384615%
- 5.0% 에픽 그룹: 14명 -> 1명당 약 0.3571428571%
- 나머지 에픽: 42명 -> 1명당 약 0.2380952381%
- 레어: 13명 -> 1명당 5.9%
- 일반: 2명 -> 0%

[베이라시아 처리]
사용자가 제공한 6% 표에는 '베이라시아'가 있으나 현재 v2.14.27의 HEROES 256명 데이터에는 등록되어 있지 않습니다.
따라서 현재는 6%를 위키에 실제 등록된 13명이 균등 분담합니다.
확률 규칙에는 '베이라시아' 이름을 미리 넣어두었기 때문에, 추후 기존 HEROES 데이터에 동일 한국명으로 영웅이 추가되면 자동으로 6% 그룹에 합류하고 14명이 6%를 균등 분담합니다.

[구조]
- 별도 영웅 DB 생성 없음
- 기존 HEROES 데이터 재사용
- 신규 전설/에픽/레어 영웅은 특별 그룹에 명시되지 않는 한 자동으로 해당 '나머지 희귀도 그룹'에 포함됩니다.
- crypto.getRandomValues() 난수 방식 유지
- 확률 합계 100% 자동 검증 유지
- LocalStorage/로그인/DB/소환 기록 없음

주의: v2.14.27 이후 별도로 수정된 최신 _worker.js가 있다면 이 파일로 통째로 덮어쓰지 말고 확률 패치 부분만 병합해야 합니다.
