worwiki v2.14.27 — 영웅 1회 소환 미니게임
기준: v2.14.26-volka-tide-growth-patch

[적용]
1. 기존 위키 최상위의 _worker.js를 이 ZIP의 _worker.js로 덮어씁니다.
2. Cloudflare Pages에 재배포합니다.
3. 배포 후 https://worwiki.kr/summon/ 접속으로 확인합니다.

[이번 패치 범위]
- /summon/ 신규 미니게임 페이지
- 기존 _worker.js의 HEROES 데이터 256명을 소환 대상으로 자동 재사용
- 별도 영웅 DB/LocalStorage/로그인/서버 저장 없음
- 1회 소환 → 약 2.25초 CSS 연출 → 영웅 1명 공개
- crypto.getRandomValues() 기반 난수
- 결과: 영웅 이미지 / 희귀도 표시 / 한국명·영문명 / 상세페이지 이동 / 다시 소환
- 모바일 반응형 대응 및 이미지 object-fit:contain 처리
- 실제 확률 입력 전에는 '전체 영웅 균등 테스트 모드' 문구가 페이지에 표시됨

[확률 설정 위치]
_worker.js 안의 다음 블록만 수정하면 됩니다.

const WW_SUMMON_CHANCES = Object.freeze({});

실제 확률 전달 후에는 모든 영웅 ID를 0~1 사이 값으로 입력하고 전체 합계를 정확히 1.0으로 맞춥니다.
예: 0.05 = 5%

확률표에 아래 문제가 있으면 /summon/ 페이지가 500 오류로 중단되어 잘못된 확률로 배포되지 않게 했습니다.
- 위키에 없는 영웅 ID
- 기존 영웅 ID 누락
- 음수/1 초과/숫자가 아닌 값
- 전체 합계가 1.0이 아님

[주의]
- 이번 버전에서는 메인 화면에 미니게임 진입 버튼을 추가하지 않았습니다. 기존 UI를 건드리지 않고 /summon/ 페이지만 추가했습니다.
- 실제 영웅별 확률은 사용자 확정값을 받은 다음 WW_SUMMON_CHANCES 블록만 교체하면 됩니다.
