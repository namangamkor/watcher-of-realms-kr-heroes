worwiki v2.14.21 SEO META PATCH
기준: v2.14.20-guide-nav-spacing의 최신 _worker.js

적용 파일
- _worker.js

적용 내용
1) 영웅 상세페이지 <title> 개선
   기존: 나만겜 | 마리엘(Marri) - 워처 오브 렐름 한국 영웅 위키
   변경: 마리엘(Marri) 장비·아티팩트·각성 | 워처 오브 렐름 위키
   - OG/Twitter 제목도 같은 title 변수를 사용하므로 함께 변경됩니다.
   - 화면의 H1/디자인/본문은 변경하지 않습니다.

2) 영웅별 meta description 자동 생성
   예시:
   워처 오브 렐름 마리엘(Marri)의 한국명·영문명, 진영, 추천 장비, 각성 A1~A5, 추천 아티팩트와 유저 후기를 확인하세요.
   - 모든 영웅 상세페이지에 hero.nameKr / hero.nameEn 값으로 자동 적용됩니다.
   - JSON-LD / OG / Twitter description도 동일한 description 값을 사용합니다.

3) 장비 프리셋 401~424 검색 제목 개선
   내부 관리명(예: 나만겜407_속분서폿)을 검색 제목으로 쓰지 않고,
   사람이 이해하기 쉬운 역할명을 <title>에 사용합니다.

   예시:
   /gear-preset-401
   범용 딜러 장비 프리셋 | 워처 오브 렐름 - 나만겜

   /gear-preset-407
   속도·분노수급 서포터 장비 프리셋 | 워처 오브 렐름 - 나만겜

   - 페이지 본문 H1과 나만겜4XX 관리코드는 그대로 유지합니다.
   - URL도 변경하지 않습니다.
   - 기존 OG/Twitter title 태그가 있으면 동일 제목으로 함께 교체합니다.

배포 방법
1. 현재 프로젝트 루트의 _worker.js를 이 패치의 _worker.js로 교체합니다.
2. Cloudflare Pages에 재배포합니다.
3. 아래 URL 소스 또는 브라우저 탭 제목을 확인합니다.
   - https://worwiki.kr/hero/marri/
   - https://worwiki.kr/hero/isolde/
   - https://worwiki.kr/gear-preset-401
   - https://worwiki.kr/gear-preset-407

주의
- 이번 패치는 SEO 메타 정보만 변경합니다.
- 메인 카피, 영웅 상세 UI, 장비 프리셋 UI, URL 구조는 건드리지 않습니다.
- 검색결과의 실제 제목/설명 반영은 Google 재크롤링 이후 시간이 걸릴 수 있습니다.
